# 脱敏导入兼容样表

本目录中的姓名、学号、联系方式和内容均为虚构数据，仅用于辅导员工作台 v3.9 的导入验收。

- `01`–`03`：UTF-8、BOM、标题行和高校常见字段别名。
- `04`：敏感字段保留在模板中，但示例值为空。
- `05`–`08`：完全重复、同学号冲突、待确认及非法字段。
- `09`：CSV 公式文本安全处理。
- `10`：分号分隔的异常文件，应提示字段无法识别，不得误写。
- `11`：GB18030 编码。
- `12`：XLSX 多工作表、合并式标题行，模拟 Excel / WPS。
- `13`：Excel 97–2003 XLS，供 WPS / LibreOffice 兼容检查。

重新生成二进制样表：`pnpm run samples:generate`。
