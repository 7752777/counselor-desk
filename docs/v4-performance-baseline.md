# v4.0 性能基线与验收记录

## 当前可复现基线

- 环境：Windows 参考工作区，Node.js 运行回归脚本。
- `tests/import-scale.js`：5000 行导入基线 154 ms（脚本级耗时，不能替代四核/8GB/SSD 真机验收）。
- 单 HTML v4 发布包当前约 3.69 MB，包含主线程兼容运行时、Worker 内嵌 SheetJS、JSZip、Argon2id WASM/JS 和 ECharts 离线资源；桌面版通过安装包文件分离避免重复下载。
- Excel/CSV 预览在发布包中通过内嵌 Import Worker 执行，桌面源码版通过 `src/core/import-worker.js` 加载；Worker 不可用时才回退到主线程解析。
- 分段导入检查点写入本地兼容仓储，临时学生区写入 IndexedDB；取消或应用重启后重新选择同一文件可按文件哈希、工作表、表头行和映射版本继续。
- `tests/regression.js`：29 个视图均可渲染，运行时错误 0。
- `tests/v40-runtime.js`：分段导入进度、断点恢复和备份加解密通过。

## 发布门禁

真机验收仍需记录 0/1/100/5000/10000 行、100 列表格、每 500 ms 进度更新、主线程连续阻塞不超过 200 ms，以及断电/取消/文件变化等异常场景。99.7% 成功率只在不少于 100 份脱敏表格、覆盖不少于 20 种格式后计算，不以脚本基线代替运营指标。
