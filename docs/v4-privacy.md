# v4.0 隐私与敏感个人信息说明

辅导员工作台 v4.0 是本地优先工具，不建设账号、云同步、服务器端学生数据库或自动联网就业抓取。网页端数据留在浏览器 IndexedDB；Windows 桌面端使用加密记录仓储和附件保险库。用户负责设备账户、磁盘和备份口令的安全。

学生身份证件、联系方式、家庭信息、心理健康、政治面貌、照片和相关附件按敏感个人信息处理，只在明确工作需要的范围内采集、查看、导出和恢复。敏感导出、恢复、删除、迁移、批量导入和党员节点办理会写入本地审计日志。

照片功能只依据学号精确匹配、唯一姓名匹配或已经建立的归档关系定位学生。本版本不进行人脸相似匹配，不采集人脸特征，不生成生物特征向量，也不把第三方页面内容写入学生档案。

加密备份口令无法找回；忘记口令、丢失设备密钥或删除本地备份可能导致数据不可恢复。公开演示、测试和运营报告必须使用脱敏或虚构数据，真实样本不得提交到代码仓库或公共服务。
