# 三分钟开始使用

这页给第一次使用辅导员工作台的普通用户。只需选一种打开方式，不需要安装 Node.js、pnpm、Git，也不需要打开命令行。

## 先选一种方式

| 你的情况 | 选择 | 怎么做 |
| --- | --- | --- |
| 日常在 Windows 电脑上使用 | Windows 桌面版 | 在 [GitHub Release](https://github.com/7752777/counselor-desk/releases) 下载显示为 `辅导员工作台-v4.0.0-Windows-安装版.msi` 的附件，双击后按默认选项安装。 |
| 不想安装，或临时在别人的电脑上使用 | 网页离线版 | 下载显示为 `辅导员工作台-v4.0.0-网页离线版.html` 的附件，双击文件即可打开。 |
| 在 Mac 上使用 | macOS 桌面版 | 下载显示为 `辅导员工作台-v4.0.0-macOS-安装版.dmg` 的附件，打开后把应用拖入“应用程序”。Intel 和 Apple Silicon 使用同一个包。 |

当前公开包为未签名体验版。Windows 出现“未知发布者”或 macOS 出现“无法验证开发者”时，只在确认文件来自项目 Release 后继续；需要核对文件时，下载页同时提供 Windows 和 macOS 的 SHA-256 校验清单。

## 第一次打开后做三件事

1. 先选择“体验示例”，熟悉首页、学生台账、任务和资料库，不要立刻导入真实学生信息。
2. 确认工作习惯后，选择“正式初始化”，再从“学生台账”导入 Excel 或 CSV。导入前先看字段映射和预览结果。
3. 打开“备份与迁移”，完成第一次备份。换电脑、清理浏览器或做大批量导入前，都先备份一次。

## 常见选择

- 想上传假期去向表、德育考核表、通知或政策文件：进入“模板库 → 分类文件库”，上传后确认分类和规范名称。
- 想从手机补录信息：先在桌面端导出手机工作包，手机修改后再导回桌面端查看差异并合并。
- 想找某位学生的记录：从学生台账搜索姓名、学号或班级，再进入相关台账处理谈话、预警和任务。
- 想更换电脑：不要只复制安装包或 HTML 文件，应从“备份与迁移”导出并恢复备份。
