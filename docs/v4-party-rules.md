# v4.0 党员发展规则版本说明

## 默认规则源

工作台默认规则版本为 `2026-05-11`，对应修订后的《中国共产党发展党员工作细则》。规则以版本号写入每条党员发展档案和节点审计记录；学校可以增加本校材料或审批节点，但不能删除、缩短或绕过强制节点。

## 五阶段模型

1. 申请入党
2. 积极分子培养
3. 发展对象考察
4. 接收预备党员
5. 预备党员教育考察与转正

系统校验年满十八岁、一个月内完成谈话、不少于一年培养考察、不少于五个工作日公示和预备期一年，并检查材料完整性与节点顺序。退回操作应记录原因；节点记录同时保存办理人、办理时间、材料状态和规则版本。

## 合规边界

系统只提供资格提示、时限提醒、材料完整性和顺序校验，不自动作出政治审查、发展资格或转正结论。政治面貌、思想汇报和相关附件按敏感个人信息处理，导出和恢复应遵守学校权限与最小必要原则。

规则源更新时应新增规则版本和迁移说明，不直接覆盖历史档案使用的规则版本。
