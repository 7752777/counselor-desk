# 辅导员工作台使用手册

> 面向一线辅导员老师的本地化学生工作工具。无需安装、无需登录，双击一个 HTML 文件即可使用。

**适用版本：v4.0.0　|　更新日期：2026-08-07**

---

## 这份手册解决什么问题

辅导员的日常工作往往分散在学生名单、任务清单、谈话记录、专项台账和阶段小结里。本工作台把这些高频工作收进一个页面，帮助你：

- 先看今天最需要处理的事项，减少漏办和逾期；
- 把学生、任务、谈话和专项工作放在同一个本地工作台里；
- 用关注等级、危机预警、回访日期形成持续跟进；
- 从平时记录直接生成周报、月报或阶段小结；
- 通过 CSV、Excel 大表和 JSON 备份带走数据。

本工具定位为**个人工作台**，不是多人协同系统，也不替代学校正式业务系统。

## 启动与第一步

v4.0 提供 Windows/macOS 桌面版和单 HTML 网页版，业务数据结构一致，但默认都只保存在当前设备：

| 运行方式 | 启动方法 | 推荐用途 |
| --- | --- | --- |
| **单 HTML 网页版** | 双击发布包中的 `辅导员工作台.html`；仓库开发版使用 `index.html` | 零安装、离线使用、手机临时查看和录入 |
| **Windows 桌面版** | Release 中双击 `counselor-desk-4.0.0-x64.exe`；不想安装可运行 `counselor-desk-4.0.0-portable.exe` | 日常主工作区、SQLite、照片和本地附件 |
| **macOS 桌面版** | Release 打开 `counselor-desk-4.0.0-mac-universal.dmg`，拖入“应用程序”；也可使用 ZIP | Intel / Apple Silicon 通用桌面工作区 |

开发者如果要通过本机 HTTP 预览网页，先执行 `pnpm install --frozen-lockfile`，再运行 `pnpm run web:dev`，打开 `http://127.0.0.1:4173`。构建命令如下：

```powershell
pnpm run build:release     # output/辅导员工作台.html
pnpm run desktop:build        # Windows output/desktop/ 安装版与便携版
pnpm run desktop:build:mac    # macOS universal DMG + ZIP（需在 macOS runner）
```

普通用户不需要安装 Node.js、pnpm 或 Electron。Windows 安装版按当前用户安装，不要求管理员权限；macOS 版打开 DMG 后拖入“应用程序”；网页端仍可双击 HTML。桌面版安装、备份和数据路径见 [桌面版安装与数据路径](v4-desktop-installation.md)。下面的业务步骤三种运行形态均适用。

## 一、30 秒开始使用

### 1. 打开工作台

1. 普通用户可打开桌面版快捷方式，或双击发布包中的 `辅导员工作台.html`；仓库开发版对应文件名是 `index.html`。
2. 推荐使用新版 Chrome 或 Edge。
3. 首次打开会载入示例数据，页面会出现“当前展示的是示例数据”的提示。

电脑适合日常录入和批量整理；手机浏览器也能打开，适合临时查看和简单修改。手机上可以使用浏览器的“添加到主屏幕”功能，之后像打开一个轻量 App 一样进入。

### 2. 先完成两项初始化

1. 点击首页提示中的“清空示例数据”。这只会清除示例数据，不会删除你之后录入的真实数据。
2. 进入左侧“平台联动”，填写“辅导员姓名”和“学院 / 院系”。点击其他位置后会自动保存。

如果只是想熟悉功能，可以保留示例数据；正式录入前请先清空。

### 3. 推荐的第一次使用顺序

1. 在“学生台账”导入或录入学生。
2. 在“工作任务”登记近期截止事项。
3. 在“谈心谈话”补录最近的谈话，并填写是否需要回访。
4. 在“重点学生档案”首次进入时设置 4 位保护锁。
5. 在“平台联动”生成一份完整备份。

完成后，首页的提醒、统计和工作小结才会逐渐贴合你的实际工作。

## 二、每天怎么用首页

首页“今天要处理”是工作台的主入口。它会按照紧急程度聚合需要处理的事项，常见来源包括：

- 未解除的心理危机预警；
- 重度且未结案的心理摸排；
- 一级重点学生的周期谈话；
- 红色未解除的学业预警；
- 请销假逾期、工作节点到期、竞赛截止提醒；
- 任务逾期、今天截止和临近截止事项；
- 已到回访日期的谈话记录。

建议每天按以下顺序处理：

1. 先看红色和“未解除”事项，确认是否需要立即联系学生、家长或相关部门。
2. 处理到期的回访、销假和工作节点。
3. 清理逾期任务；不适合当天完成的事项，可使用“顺延一天”。
4. 新增当天的谈话、学生诉求和临时任务。
5. 下班前检查首页是否仍有遗漏，并按需要生成工作小结。

### 首页上的几类信息

| 区域 | 用途 |
| --- | --- |
| 今日要处理 | 聚合风险、回访、到期事项和任务 |
| KPI 卡片 | 查看逾期未办、在办任务、重点学生、危机预警、本月谈话 |
| 快速记录 | 一步新建任务、谈话、学生或工作小结 |
| 近半年工作趋势 | 对比谈话次数和新增任务 |
| 九项职责工作量 | 按职责查看近期任务与谈话投入 |
| 学生关注结构 | 查看危机、重点关注和普通在读学生的结构 |
| 数据洞察 | 查看任务逾期率、谈话覆盖率和重点关注占比 |

> 昨天没有完成的事项不会自动消失。只要记录仍处于未完成、未解除或待回访状态，它会继续出现在工作台的提醒中。

## 三、学生台账：先把学生数据放进来

进入左侧“学生台账”，可以使用“新增学生”逐条录入，也可以使用“导入 CSV”批量导入。

### 1. 从 Excel 大表导入

当前“导入 CSV”按钮同时接受 `.csv`、`.txt`、`.xls` 和 `.xlsx` 文件。导入学校信息化门户或学工系统导出的学生大表时：

1. 点击“导入 CSV”。
2. 选择 `.xls` 或 `.xlsx` 文件。
3. 工作台会尝试识别常见表头，例如学号、学生姓名、班级、专业、年级、学院、辅导员、政治面貌、手机号、宿舍、身份证、邮箱和家长电话。
4. 检查导入预览后确认。

导入规则：

- 以学号作为主要识别依据，学号始终按文本保存并保留前导零；
- 学号和姓名必须同时存在才能直接提交，缺少任一项的记录进入“待确认”；
- 同一学号内容完全一致时自动合并，不同内容会标记冲突并要求选择；
- 日期、手机号、邮箱、身份证号、学制和枚举值显式校验，错误原文会保留在报告中；
- 确认前不会写入，提交前自动生成快照；写入异常时整批回滚；
- `.xls/.xlsx` 由发布包内置的 SheetJS 0.20.3 离线解析，支持选择工作表和表头行，不需要联网；
- 学生模板中的身份证号、家庭地址、家长电话等列带有“敏感”标记，填写前请按本校制度确认。

### 2. 重点关注与危机预警

学生档案中可以设置：

- 关注等级：一级（重点）、二级（关注）、三级（一般）；
- 关注类型：心理关注、学业预警、经济困难、身体状况、就业困难、行为纪律、家庭特殊；
- 心理危机预警级别：校级或院级；
- 发现方式：自我报告、普查发现、其他人发现；
- 是否已解除。

关注等级会影响首页的周期提醒：

| 等级 | 建议周期 | 首页行为 |
| --- | --- | --- |
| 一级（重点） | 7 天 | 到期后优先提醒，建议每周至少谈话一次 |
| 二级（关注） | 14 天 | 到期后进入周期跟进 |
| 三级（一般） | 30 天 | 到期后进入常规关注 |
| 不设关注 | 不参与周期提醒 | 作为普通学生管理 |

### 3. 查找学生

学生台账内可以按姓名、学号、宿舍或备注搜索，也可以按班级、学生状态和关注类型筛选。每条记录提供“档案”“谈话”“删除”等操作。

顶部全局搜索还可以跨学生、任务和谈话记录查找内容。点击结果后会跳转到对应模块。

## 四、工作任务：把事情变成清单

进入“工作任务”，点击“新建任务”。建议至少填写：

- 任务名称；
- 职责分类；
- 来源；
- 涉及班级或范围；
- 截止日期；
- 优先级；
- 备注或具体要求。

优先级建议这样使用：

- **P0 / 紧急**：今天必须处理，或存在明确风险；
- **P1 / 常规**：按正常时间推进的工作；
- **P2 / 长期**：周期性、准备性或可以排期的工作。

任务列表支持按“未完成 / 已完成 / 全部”筛选、按职责分类过滤、关键词搜索、批量完成、CSV 导入和 CSV 导出。逾期任务会在首页和列表中突出显示。

## 五、谈心谈话：记录一次，就留下下一步

进入“谈心谈话”或首页点击“记一次谈心谈话”。每次记录建议包含：

1. 学生姓名和日期；
2. 所属职责；
3. 谈话方式：面谈、电话、线上、家访或集体；
4. 谈话内容；
5. 问题研判；
6. 处理措施；
7. 是否需要回访和回访日期。

只填写“谈过了”而不写研判和措施，后续很难形成连续记录。建议用“情况—判断—措施—下一步”的顺序写：

> 学生反映了什么情况 → 当前风险或需求如何 → 已采取什么措施 → 什么时候、由谁继续跟进。

需要回访的记录会在到期后回到首页。点击“已回访”可以完成跟进，也可以从首页继续新建一次谈话。

## 六、重点关怀与心理摸排

### 1. 重点学生档案

首次进入“重点学生档案”时，需要设置 4 位数字保护锁。之后查看档案需要验证密码，也可以手动上锁。

保护锁用于防止误触和旁人直接查看，属于轻量防护，不等同于高强度加密。密码忘记时可以保留数据并重新设置，但建议由本人妥善保管密码。

### 2. 心理摸排

“心理摸排”可以记录量表、得分、等级、处理人或转介去向，以及是否结案。支持 PHQ-9、GAD-7、SCL-90、SAS 和自编问卷等记录方式。

重度且未结案的记录会在首页置顶提醒。工作台只负责记录和提醒，不替代专业心理评估、危机处置制度和学校正式流程。

### 3. 学业预警与帮扶

“学业预警”按红、橙、黄三级记录预警原因和解除状态。未解除的红色预警会在首页突出显示，可以：

- 标记解除；
- 直接建立帮扶记录；
- 查看学生档案；
- 继续记录后续谈话。

“学业帮扶”可以按学业、经济、心理、就业等类型记录帮扶人、措施和跟踪状态。

## 八、工作留痕：从平时记录生成小结

进入“工作留痕”，可以选择：

- 本月；
- 本学期；
- 自定义日期区间。

页面会汇总任务完成、谈心谈话、重点学生、危机预警、专项工作和九项职责分布，并生成一段结构化文字。生成后可以：

- 直接编辑文本；
- 复制全文；
- 下载 TXT；
- 打印或保存为 PDF。

推荐做法：平时只记录事实、判断、措施和结果，月底再生成小结。生成的文字应当由本人核对后，再粘贴到学院或学校要求的正式模板中。

## 九、数据保存、备份与迁移

### 1. 数据保存在哪里

工作台的业务数据保存在当前浏览器的 `localStorage` 中，核心业务不依赖后端服务。关闭页面不会自动删除数据，但清理浏览器缓存、换电脑、换浏览器或使用公共电脑，都可能导致你看不到原来的记录。

### 2. 建议的备份习惯

进入“平台联动”：

1. 填好辅导员姓名和学院；
2. 点击“导出完整备份”，保存 `.json` 文件；
3. 点击“生成便携工作台（数据已内置）”，得到一个自带数据的 HTML 文件；
4. 将两份文件放在安全位置，并定期更新。

便携工作台适合带到另一台电脑直接打开；JSON 备份适合在新工作台中选择“导入备份 / 交换包”恢复。跨设备不会自动同步，需要手动导出和导入。

### 3. 单个模块的数据交换

列表模块支持 CSV 导出和导入。推荐使用“模板”产生表头，避免列名错位。CSV 文件可以在 Excel 中编辑，但另存时请保留 CSV 格式。

### 4. 清空操作

“清空示例数据”只删除示例记录；“清空全部数据”会删除当前本机的全部业务数据。两者都需要二次确认。执行清空前请先导出备份。

## 十、隐私和使用边界

本工作台适合个人本地记录，但不能把“本地保存”理解成“自动加密”：

- 数据默认留在本机，不上传到工作台后端；网页版使用 IndexedDB，Windows/macOS 桌面版使用加密记录仓储和附件保险库；
- 重点学生保护锁是轻量防护，不是强加密；桌面版数据密钥由 Windows `safeStorage` 保护；
- 不建议在公共电脑上长期保存真实学生敏感信息；
- 处理完公共电脑上的数据后，应导出并清理；
- 对外分享截图、短视频或宣传图片前，必须使用示例数据或打码；
- 涉及心理、家庭、经济、身份证和联系方式的信息，应遵守学校的保密制度和最小必要原则。
- 本版本只按学号、唯一姓名或已归档照片关系定位学生，不进行人脸相似匹配，不采集人脸特征或生成生物特征向量。
- 照片、政治面貌、心理健康、身份证件等均按敏感个人信息处理；导出、恢复、删除和批量导入前应确认用途、范围和保存位置。

`.xls/.xlsx` 导入是一个例外：首次解析时会动态加载表格解析器。若工作环境要求完全断网，请提前完成一次加载，或改用 CSV 导入。

## 十一、常见问题

### 示例数据怎么删除？

点击首页提示中的“清空示例数据”，或者进入“平台联动 → 危险操作 → 清空示例数据”。

### 换电脑后数据还在吗？

不会自动跟随。请在旧电脑生成便携工作台或导出完整 JSON 备份，再在新电脑打开工作台并导入。

### 数据误删能恢复吗？

只有已经导出过 JSON 备份或便携工作台时才能恢复。因此建议首次录入完成后就做一份备份，之后按周或按月更新。

### 手机上能不能用？

可以打开、查看和做少量录入，但屏幕小、输入效率低。大批量导入和整理建议在电脑上完成。

### 需要联网吗？

核心记录、查看、CSV 数据交换和 JSON 备份可以离线使用。`.xls/.xlsx` 首次解析需要加载表格解析器，完全断网时使用 CSV。

### 保护锁是不是加密？

不是。保护锁主要防止误触和旁人直接查看，不能替代系统账户、磁盘加密或学校的信息安全措施。

### 怎么切换深色模式？

点击顶部右侧的“切换深色 / 浅色”按钮。选择会保存在本机，下次打开时继续使用上次的主题。

## 十二、给分享者的发布前检查

如果你要把工作台交给其他老师使用，建议先完成：

- 清空示例数据，或明确说明示例数据仅用于演示；
- 检查自己的辅导员姓名和学院是否已清除；
- 删除或替换截图、录屏中的真实学生信息；
- 导出并保存一份自己的数据备份；
- 将发布文件 `辅导员工作台.html` 和本手册放在同一个文件夹内；
- 向同事说明数据默认保存在各自电脑，不会自动同步；
- 说明重点档案保护锁是轻量防护，并提醒不要在公共电脑长期留存敏感信息。

## v4.0 新增功能

### 多端运行与首次使用引导

网页端和桌面端第一次打开首页都会看到上手清单：设置个人信息、导入学生名单、处理今日任务和完成首次备份。可以暂时跳过，之后在“设置 → 重新查看引导”中恢复。

### 学生大表与动态字段

学生导入会保留学校表格中的未知列，并支持生源地、培养层次和自定义字段。相同学号、不同培养层次或年份的记录不会被错误覆盖。

### 文件资料库与手机回传

“资料与平台 → 文件资料库”可以集中保存表单模板、政策文件、讲话稿、安全提示和其他工作材料；手机回传包在桌面端写入前会先展示新增、更新和删除差异，并自动生成回退快照。

### 界面个性化

进入“设置 → 界面个性化”，可选择五套配色、导入最大 4MB 的本地背景图并调整 0–35% 透明度。较大的图片会在本机自动压缩后保存，不会上传。文字可读性下降时，建议降低透明度或恢复默认外观。

### 登录锁

在“设置 → 登录锁与敏感操作”中设置 4–12 位数字密码。启用后可在启动、手动上锁、闲置超时以及删除学生、清空数据等操作时验证。登录锁属于界面访问控制，不等同于数据加密；公共电脑上不要长期保存真实敏感信息。

### 个人学习助手

左侧“资料与平台 → 学习助手”支持收集资料、跟踪进度、记录笔记、生成本地摘要和导出学习包。内容默认只保存在本机，首版不自动调用第三方 AI。

> 本手册根据当前 v4.0.0 页面和功能整理。正式工作仍应以学校现行制度、学院流程和相关专业部门要求为准。
