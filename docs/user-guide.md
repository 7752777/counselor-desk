# 用户指南入口

这是面向普通辅导员的文档入口。详细业务步骤仍保留在中文手册中，本页负责告诉读者应该先看哪一份，避免多个相似文件互相重复。

## 推荐阅读顺序

1. [开始使用](./getting-started.md)：选择 Web、Windows 或 macOS 运行形态。
2. [辅导员工作台使用手册](./辅导员工作台使用手册.md)：按日常工作流学习学生、任务、谈话、风险和资源模块。
3. [桌面版安装与数据路径](./v4-desktop-installation.md)：安装、附件保险库、卸载、备份和换电脑。
4. [迁移与备份说明](./v4-migration-and-backup.md)：JSON/.cwbk 备份、手机文件交换、合并与覆盖。
5. [隐私说明](./v4-privacy.md)：本地优先、敏感字段、附件和数据删除边界。

## 按工作问题查找

| 工作问题 | 功能入口 | 参考 |
| --- | --- | --- |
| 学校表格字段每次都不一样 | 学生台账 → 导入预览 | [数据与迁移参考](./data-contract.md) |
| 假期去向、德育考核表找不到 | 模板库 → 分类文件库 | [桌面版安装与数据路径](./v4-desktop-installation.md) |
| 校长讲话稿、安全提示分散在文件夹 | 模板库 → 政策文件/工作素材 | [用户手册](./辅导员工作台使用手册.md) |
| 手机临时改了几条记录 | 备份与迁移 → 手机文件交换 | [迁移与备份说明](./v4-migration-and-backup.md) |
| 换电脑担心照片和附件丢失 | 生成加密备份或换机包 | [隐私说明](./v4-privacy.md) |
| 想确认某个功能是否真的完成 | 验收报告与测试入口 | [v4.0 验收报告](./v4-acceptance-report.md) |

## 旧入口说明

仓库根目录的 `使用说明.md`、`docs/使用指南.md` 和 `docs/辅导员工作台使用手册.md` 是历史中文入口，暂不删除，以免公开链接失效。新内容从本页和 `docs/README.md` 进入；后续更新应优先维护 canonical 文档，避免再次复制同一段启动说明。
