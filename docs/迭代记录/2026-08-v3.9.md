# v3.9 迭代提升记录

## 迭代目标

在不破坏单文件、离线、本地优先和现有交换包兼容性的前提下，提升首次上手、界面个性化、敏感操作保护、导入容错和个人学习效率。

## 已完成

- 版本升级至 v3.9.0。
- 首次使用引导卡片，可跳过、完成和从设置恢复。
- 五套配色预设、本地背景图、透明度调节和默认外观恢复。
- 可选启动锁、手动上锁、闲置超时和敏感删除/清空二次验证。
- 学习助手资料、笔记、进度、本地摘要和学习包导出。
- 通用导入字段模糊匹配、预览 API、导入快照和撤销接口。
- 交换包 v6 纳入学习数据，旧版本继续兼容。
- 新增 v3.9 契约测试并保留原有回归测试。

## 安全边界

登录锁是界面访问控制，不是数据加密。真实学生敏感信息不建议长期保存在公共电脑；跨设备前应先导出备份并验证恢复结果。

## 测试记录

发布前运行：

```bash
pnpm test
pnpm run lint
pnpm run test:release
pnpm run check:public
```

额外检查：320–430px 竖屏、背景图可读性、锁屏恢复、学习包导出、v5 交换包导入 v6。
