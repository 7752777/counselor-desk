# v3.9 全国高校兼容性加固计划

## 范围与原则

本轮继续使用 **v3.9** 名称，重点解决首次初始化、导入健壮性、数据安全边界、浏览器兼容和开源发布体验。电脑与手机自动同步、账号体系、云端冲突解决继续留到 v4.0，本计划不提前引入同步后端。

仓库仍保留 `index.html` 作为 GitHub Pages 和 Web 服务器的技术入口；面向普通老师发布时生成中文文件名 `辅导员工作台.html`，避免破坏网站部署规则。

## 当前审计结论

### 已在本轮直接修复

- 学生大表能识别生日、籍贯、家庭地址、家长信息、学制、民族、身份证、邮箱和 QQ，但旧的 `normStudent` 会在新建或重新加载时丢弃这些字段；现已补齐数据规范化与 schema 定义。
- 无法识别学生表头时不再按固定列位置猜测并写入；旧的无表头兼容仅保留为开发接口的显式选项。
- 首次引导曾把示例老师、示例学生和示例任务误判为用户已完成初始化；现已只统计真实数据。
- 背景图输入上限提升至 4MB。为避免 Base64 膨胀后挤满 `localStorage`，超过安全存储体积的图片会在浏览器本机压缩后保存。
- 品牌副标由单一学院风格调整为“高校学生工作 · 开源版”，新增通用工作簿 / 学生 / 完成标记图标。
- 新增中文发布文件生成命令，公开网站仍使用标准 `index.html`。
- CI 从只跑 4 套旧测试改为执行完整测试和发布检查。

### 2026-08-05 实施结果

1. **确认后写入已完成。** 学生和 18 个模块均先生成预览，确认前不写入。
2. **静默覆盖已取消。** 业务记录优先按 `record_id` 更新；自然键疑似重复时进入冲突区。
3. **显式校验已完成。** 非法日期、电话、邮箱、身份证、学制、枚举、布尔和数字保留原文并标错。
4. **编码兼容已完成。** 支持 UTF-8、UTF-8 BOM、GBK/GB18030 自动识别和手动重选。
5. **Excel 完全离线。** SheetJS 0.20.3 固定打包，发布文件不访问 CDN，并附带许可证；安全审计后未采用存在公开高危漏洞的 0.18.5。
6. **持久化撤销已完成。** 导入前保存集合快照，最近三次成功导入可在数据中心跨刷新撤销。
7. **敏感字段分级已完成。** 模板保留并标注敏感列、示例留空；导入需确认，普通导出排除，敏感导出需解锁。
8. **CSV 公式注入防护已完成。** 导出时转义 `=`, `+`, `-`, `@` 开头的单元格。
9. **容量保护已完成。** 70% 显示备份提醒，85% 阻止大图片和大批量导入，写入失败不替换内存数据。

## 学生初始化字段建议

| 级别 | 字段 | 处理原则 |
| --- | --- | --- |
| 核心标识 | 学号、姓名 | 学号始终按字符串保存，保留前导零；姓名用于显示。缺任一项允许预览，但必须明确警告 |
| 强烈推荐 | 班级、专业、年级、学院、辅导员、学籍状态 | 决定筛选、统计和后续模块联动；缺失时显示“待补充”，不应静默猜测 |
| 常用可选 | 性别、政治面貌、手机号、宿舍、民族、邮箱 | 可导入、可映射，不作为去重主键 |
| 高敏可选 | 身份证、出生日期、家庭地址、家长姓名、家长电话 | 模板保留并醒目标注，示例留空；检测后单独确认，普通导出排除，敏感导出受操作锁保护 |
| 工作台字段 | 关注类型、关注等级、危机状态、备注 | 建议在学生基础名单导入完成后再补充，避免普通教务表误写风险字段 |

当前默认“缺少学籍状态时填在读”适合单一学院演示，但不适合全国数据。后续应改为“待确认”，并在预览页允许用户一次性指定默认值。

## 统一导入流程

```text
选择文件
  → 识别编码 / 工作表 / 表头行
  → 自动字段映射（可手动调整并保存为本校预设）
  → 按字段类型逐格校验
  → 预览新增 / 更新 / 冲突 / 跳过 / 未识别列
  → 自动生成导入前快照
  → 用户确认后原子写入
  → 输出导入报告，并提供撤销
```

任何解析错误、字段冲突或存储空间不足都应停在写入前；不允许出现“导入了一半”的状态。

## 分阶段实施

### 3.9-A：学生初始化安全基线

- 建立唯一的学生字段 schema，统一模板、导入、导出、表单、文档和校验。
- 实现真正的导入预览与确认；默认不再接受无表头固定顺序导入。
- 未识别列进入“暂不导入”区，不直接丢弃，也不写入未知字段。
- 加入导入前快照、原子提交、刷新后仍可撤销一次。
- 输出逐行错误报告，可下载为 CSV 后修正。

验收：错误表头、空文件、重复学号、前导零学号、同名学生、5000 行数据均不会造成部分写入或页面崩溃。

### 3.9-B：全国高校字段映射

- 支持选择 Excel 工作表和表头所在行，兼容前置标题、合并表头、空列。
- 增加 GBK / GB18030 编码识别与手动切换。
- 用户可保存“本校字段映射预设”，例如“行政班名称 → 班级”。
- 日期、枚举、布尔、金额提供显式转换规则和异常值提示。
- 学号全程作为文本，避免科学计数法和前导零丢失。

验收：至少使用 10 种不同高校 / 学工系统的脱敏样表建立兼容样本库。

### 3.9-C：18 个模块统一导入契约

- 每个模块声明 required / optional / sensitive / aliases / type / enum / mergeKey / validator。
- 模板、导出列、导入映射和帮助文案由同一 schema 生成，避免四处维护不一致。
- 去重优先使用学号；无法唯一判断时显示冲突，不静默覆盖。
- 同一天多次谈话、考勤、心理测评等允许并存。
- CSV 导出增加公式注入转义。

验收：18 个模块完成“模板 → 修改 → 预览 → 导入 → 撤销 → 再导出”闭环测试。

### 3.9-D：公开发布兼容与体验

- 首次启动改为三步初始化向导：体验示例、正式建库、完成首份备份。
- 增加浏览器能力检查和存储容量健康提示。
- 明确支持矩阵：Windows Chrome / Edge，Firefox，macOS Safari；不支持 IE 和老旧内核。
- 覆盖 320px–1920px、系统缩放 125% / 150%、键盘操作和减少动画模式。
- 发布包提供 `辅导员工作台.html`、使用手册、字段字典、脱敏样例和校验报告。

## 进入 v4.0 前的门槛

只有当学生初始化和 18 个模块导入都达到“预览、校验、原子写入、可撤销、可复现测试”后，才开始电脑与手机同步。否则同步只会把错误和冲突更快地传播到更多设备。
