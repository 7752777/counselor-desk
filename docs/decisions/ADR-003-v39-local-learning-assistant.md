# ADR-003: v3.9 学习助手先做本地闭环

## Status

Accepted

## Date

2026-08-05

## Context

用户希望把政策智库和素材收藏升级为个人学习助手，同时工作台的隐私边界是本地优先、不向第三方发送学生敏感信息。

## Decision

v3.9 新增资料、笔记、学习进度、学习记录、本地规则型摘要和 Markdown/TXT/HTML/JSON 导出。保留 `CWB.learning` 的未来 provider 接口，但不内置第三方 AI 密钥、不自动上传内容。

## Consequences

- 资料和笔记在离线环境可用，隐私边界清晰。
- 自动摘要能力有限，后续可在用户明确配置服务或安全代理后接入 AI。
- 学习数据进入 JSON 备份和 v6 交换包，需持续维护兼容性。
