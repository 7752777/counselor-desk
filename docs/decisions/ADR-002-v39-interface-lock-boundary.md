# ADR-002: v3.9 采用界面访问锁而非数据加密

## Status

Accepted

## Date

2026-08-05

## Context

工作台包含重点学生、心理摸排、学业预警等敏感信息。当前已有重点档案轻量锁，但删除、清空和其他敏感操作没有统一的二次验证。

## Decision

v3.9 增加可选启动锁、闲置锁和敏感操作二次验证。密码只用于界面访问控制；设置页、帮助文档和锁屏均明确说明 `localStorage` 未加密。后续若需要真正的数据保护，另行设计 Web Crypto 加密迁移，不在本版本伪装成已加密。

## Consequences

- 可防止旁人直接打开页面和误操作删除。
- 不能防止开发者工具、浏览器配置或恶意脚本读取本地数据。
- 敏感数据仍应避免长期存放在公共电脑，跨设备使用前应导出并妥善保管备份。
