# ADR-004: v3.9 统一导入预览与撤销契约

## Status

Accepted

## Date

2026-08-05

## Context

各业务模块已经支持 CSV 导入，但不同来源的列名、空值和列顺序差异较大。导入失败或误覆盖会直接影响本地台账。

## Decision

所有通用 CSV 导入都经过字段模糊匹配、预览、主键识别和结果统计；空值默认不覆盖已有值；每次导入保留最近快照，可撤销。无法识别主键时不落库，并给出可操作提示。

## Consequences

- 导入不会因为单行异常而中断整批处理。
- 需要为每个模块维护字段同义词、主键和归一化规则。
- 撤销记录只保留本机最近若干次，清理浏览器数据前仍应先备份。
