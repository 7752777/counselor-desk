# ADR-005：v3.9 完全离线、原子化统一导入

## Status

Accepted，取代 ADR-004 中仅针对 CSV 和内存撤销的范围。

## Date

2026-08-05

## Context

公开版需要处理来自不同高校、Excel/WPS/LibreOffice 和不同编码的表格。直接写入、按姓名合并、运行时加载 CDN 或把非法值改成默认值，都会让首次初始化变得不可恢复。

## Decision

- 学生和 18 个业务模块共享 `ImportSchema`，模板、映射、校验、导入和导出由同一契约驱动。
- 导入必须先产生 `ImportPreview`；用户确认前不写数据。
- 学生只按学号合并，学号与姓名缺一则进入待确认区；业务记录优先按 `record_id` 更新。
- 提交前持久化完整集合快照，整批写入失败时恢复历史记录并保持原集合不变；最近三次成功导入可跨刷新撤销。
- SheetJS 0.20.3 固定打包到发布 HTML，不访问运行时 CDN，并随包保留许可证；不采用存在公开高危漏洞的 0.18.5。
- CSV 自动识别 UTF-8/GB18030，导出执行公式注入转义；敏感字段需要显式确认。

## Consequences

- 单文件发布体积增加约 0.9MB，但获得完全离线 Excel 导入能力。
- 浏览器 `localStorage` 容量仍有限，因此 70% 提醒备份、85% 阻止大图片和大批量导入。
- 撤销保存的是集合级快照，连续大批量操作前仍应导出完整 JSON 备份。
- v3.9 仍不提供账号、云端同步或数据库加密，这些边界必须在界面和文档中明确。
