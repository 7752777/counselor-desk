# ADR-001: v3.9 继续单文件与本地优先

## Status

Accepted

## Date

2026-08-05

## Context

当前工程以单个 `index.html` 双击运行，数据保存在浏览器本地，已有便携 HTML、JSON 备份和 `window.CWB` 扩展接口。v3.9 需要增加引导、主题、安全锁、学习资料和导入能力，但用户仍需要离线、低门槛和可携带使用。

## Decision

v3.9 保持单文件和 local-first 架构，不引入构建流程、账号体系或强制后端。新增能力通过现有 `CWB` API、版本化数据集合和设置迁移加入。PWA 与多端同步延后到 v4.0，届时同时保留单文件发行版。

## Alternatives Considered

### 立即拆分为模块化工程

可维护性更好，但会破坏双击即用和现有便携 HTML 交付方式，超出本期风险边界。

### 立即引入云端同步

可直接解决多端同步，但需要账号、服务端、冲突合并和敏感数据治理，不适合作为 v3.9 的本地体验迭代。

## Consequences

- 保持现有用户打开方式和 v1–v5 数据兼容。
- 单文件体积继续增长，必须依靠契约测试和分区注释维护。
- v4.0 需要设计单文件版与 PWA 版之间的导出、迁移和行为一致性。
