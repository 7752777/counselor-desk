# v4.0 用户体验第二轮优化计划

## 本轮已落地（v4.0 integration cleanup）

- 独立 V4.0 导航组已移除；旧 `photos/org/party/files/employment/backup` 入口保留为父板块标签兼容路由。
- 学生台账统一为“台账 / 照片管理 / 数据分析”三个内部标签，照片上传、人工确认和分析下钻均在学生台账上下文内完成。
- 桌面端业务数据不再由 `localStorage` 直接承载；渲染层通过异步仓储快照和写入队列访问 SQLite/附件保险库。
- 导航、操作栏、照片卡片和分析卡片增加基础字号、间距、换行和移动端布局约束。

## 发布前仍需关注

- Windows 正式代码签名证书仍是公开发布门禁；本地未签名包不得作为正式安装包分发。
- `99.7%` 导入成功率仍需至少 100 份脱敏表格、20 种格式和人工来源登记后才能对外公布。

## 已落地基线

- 首页提供“今天要处理、待确认照片、最近导入、党建待办、备份状态”入口。
- 学生台账支持表格、卡片、照片三种模式，以及学号、姓名、班级、宿舍、楼栋、生源地和成绩排序。
- 导入、照片、文件和资源清单统一使用进度、取消、恢复、错误原因与下一步提示。
- 环形图、趋势图和楼栋热力图共享学生筛选模型，点击图表可下钻学生明细。
- 桌面版继续作为完整体验，网页版只承担离线兼容和移动查看。

## v4.1 体验门禁

1. **任务流**：为导入、照片确认、备份恢复和批量组织导入统一任务中心，支持重试、撤销和失败报告。
2. **信息密度**：对百列导入预览、长文本和移动端表格继续做虚拟滚动、列宽记忆和横向滚动检查。
3. **无障碍**：逐页完成键盘顺序、焦点可见、表单错误关联、对比度和 200% 缩放验收。
4. **性能**：在四核/8GB/SSD 参考机上持续记录 500ms 进度频率和 200ms 主线程阻塞指标，形成可追溯报告。
5. **隐私提示**：身份证、心理、政治、照片、删除和恢复操作继续采用情境化确认，并把原因、影响、下一步写在同一提示中。

## 发布前外部依赖

- Windows 正式公开包必须注入组织代码签名证书；当前本机仅能生成未签名安装包和便携包，不能把未签名文件标为正式发布物。
- 99.7% 导入成功率只有在收集不少于 100 份脱敏表格、覆盖不少于 20 种格式并保存报告后才可对外发布。
