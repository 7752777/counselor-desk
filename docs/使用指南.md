# 使用指南

本指南面向一线辅导员，介绍如何把「辅导员工作台」用起来。无需任何技术背景。

**当前版本：v4.0.0**。本项目同时提供 Windows 桌面版和单 HTML 网页版：网页端适合零安装和手机临时使用，桌面端适合长期保存本地数据库、照片和附件。

---

## 1. 打开方式

- **电脑**：双击 `index.html`，用 Chrome / Edge / Safari 等任意浏览器打开。
- **手机**：用手机浏览器打开文件（微信里可直接打开 HTML），然后「分享 → 添加到主屏幕」，之后像 App 一样点击进入，离线也能用。底部 Tab 栏支持单手操作。
- **首次打开**：自动载入覆盖各模块的示例数据（学生 / 任务 / 谈话 / 走读 / 去向 / 评优，以及全量专项模块：请销假、考勤、工作节点、学业预警、帮扶、奖助、重点学生档案、心理摸排、就业、政策智库、素材收藏、科创竞赛、模板库等），其中含 1 条逾期任务、1 条逾期竞赛等，用于演示红色提醒。示例数据全部带标记，可一键清空。

### Windows 桌面版

普通用户优先下载并双击 `counselor-desk-4.0.0-x64.exe`。它按当前用户安装，不要求管理员权限，会创建桌面和开始菜单入口；不想安装时可运行 `counselor-desk-4.0.0-portable.exe`。桌面版的附件保险库实际路径请在“模板库 → 分类文件库”页面查看，不要把仓库的 `output/desktop/` 当成用户数据目录。完整安装说明见 [Windows 桌面版安装与数据路径](v4-desktop-installation.md)。

开发者先运行 `pnpm install --frozen-lockfile`，再执行 `pnpm run desktop:dev`。如果只想预览网页，执行 `pnpm run web:dev` 后打开 `http://127.0.0.1:4173`；构建网页发布包和桌面包分别使用 `pnpm run build:release` 与 `pnpm run desktop:build`。

## 2. 首页 · 今日概览

打开后第一屏就是「今日要处理」，它自动聚合各类需处理事项（按紧急度从高到低）：

- **心理危机预警**（未解除的学生**红色置顶**，优先级最高）；
- **学业预警·红色未解除**（红 / 橙 / 黄三级中的红色，集中盯防）；
- **重点学生·一级**（跟踪中者在首页置顶，需及时跟进）；
- **心理摸排·重度未结案**（量表重度且未结案，提示处理人）；
- 请销假的**销假逾期**提醒；
- **工作节点**到期 / 今天截止 / 进入「提前提醒天数」的周期工作；
- **科创竞赛**报名截止临近（14 天内）或已逾期的赛事；
- **重点关注学生**按等级该谈的周期到了；
- **逾期 / 今天该做 / 3 天内到期**的任务；
- **谈话回访**已到期的记录。

每条都有「一键处理」按钮，点一下即可标记完成或跳转到对应模块（记录谈话 / 确认销假 / 标记解除 / 完成节点 / 建帮扶记录等）。

> 铁律：昨天没做完的事，不会凭空消失，会自动滚到今天的列表里。

首页还提供：

- **KPI 卡片**：逾期未办 / 在办任务 / 重点关注学生 / 心理危机预警数 / 本月谈话 —— 数字带滚动动画，左侧彩色指示条，并标注「较上月」环比；
- **学生关注结构环形图**：心理危机未解除 / 重点关注 / 其余在读三档占比，中心显示「需关注 N 人」；
- **数据洞察卡**：任务逾期率、本月谈话覆盖率、重点关注占比，各带数值与一句结论，超阈值自动变色提示；
- **近半年工作趋势折线图**：谈话次数 vs 任务量双序列；
- **快速记录**：随手记一条任务或一次谈话或新增学生；
- **九项职责工作量**：按 43 号令九大职责统计你近期投入，横向柱状图展示（带生长动画）。

## 3. 工作任务

三种状态：**待办 / 进行中 / 已完成**。每条任务可设置：

- **职责归属**：九大职责之一（决定首页工作量统计）；
- **优先级**：P0 紧急 / P1 常规 / P2 长期；
- **来源**：学校下发 / 学院安排 / 平台下发 / 自主计划 / 学生诉求；
- **截止日期**：`due`；
- **说明**：`desc`；
- **关联平台任务 ID**：`platform_ref`（与重型平台联动时用，可选）。

新增任务：点「+ 新建任务」填写表单即可。逾期任务在首页和列表里标红。支持 CSV 导出。

## 4. 学生台账

花名册 + 重点关注 + 心理危机预警三层。

字段分三类：
- **与平台对齐的字段**（便于将来联动）：学号、姓名、性别、班级、专业、年级、学院、辅导员；
- **校准后的本地字段**（参照本院真实表格）：**学生当前状态**（在读/休学/复学/退学/毕业/结业）、**政治面貌**（中共党员/预备党员/入党积极分子/共青团员/群众/其他）、手机号、宿舍；
- **心理危机预警字段**（参照《心理危机预警库分级名单》）：**危机级别**（校级/院级）、**发现方式**（自我报告/普查发现/其他人发现）、**是否已解除**；
- **其他本地扩展**：重点关注类型、关注等级、备注。

**重点关注类型**：心理关注 / 学业预警 / 经济困难 / 身体状况 / 就业困难 / 行为纪律 / 家庭特殊。

**关注等级 → 回访周期**：

| 等级 | 名称 | 建议周期 | 说明 |
| --- | --- | --- | --- |
| L1 | 一级（重点） | 每 7 天 | 建议每周至少谈话 1 次 |
| L2 | 二级（关注） | 每 14 天 | 建议每两周谈话 1 次 |
| L3 | 三级（一般） | 每 30 天 | 建议每月谈话 1 次 |
| — | 不设关注 | — | 不纳入周期提醒 |

系统会根据「最后谈话日期 + 等级周期」自动算出该谈的时间，并在首页提醒。支持 CSV 导入/导出。

## 5. 谈心谈话

每次谈心谈话记一条：

- 日期、学生、所属职责、谈话方式（面谈 / 电话 / 线上 / 家访 / 集体）；
- **研判**：本次谈话的判断与结论；
- **是否需回访**：勾选后进入回访队列；
- **回访完成**：处理后在首页标记。

周期谈话提醒：重点关注学生到达等级周期时，首页自动列出「该谈了」。支持 CSV 导出。

## 9. 专项模块

以下模块聚焦事务考勤、学业资助、重点关怀与就业、资料平台四类场景，按四期交付。

### 9.1 请销假（第一期）
登记学生请假，含姓名/学号/班级、起止时间、请假类型（事假/病假等）、事由、审批人、审批状态。支持审批（通过/驳回）、销假、CSV 导出。待审批请假会在首页提示。

### 9.2 考勤管理（第一期）
记录缺勤（旷课/迟到/早退/其他），按班级、月份筛选，含本月考勤月度报表导出。登记时可关联学生台账自动带出学号/班级。

### 9.3 工作节点（第一期）
管理周期性工作（如主题班会、谈心谈话计划、材料报送）。设截止日期与「提前提醒天数」，到期前自动在首页提醒；支持日/周/月周期重复。可标记完成、写工作小结。

### 9.4 学业预警台账（第二期）
记录挂科过多/学分不足/旷课过多/学业困难等预警，分**红/橙/黄**三级。未解除的红色预警在首页**红色置顶**，可一键「标记解除」或「建帮扶记录」（从预警预填学生信息）。

### 9.5 学业帮扶台账（第二期）
对预警等学生建立帮扶记录，分学业/经济/心理/就业四类。跟踪中/已结束状态，可由学业预警一键转入。支持 CSV 导出。

### 9.6 奖助勤补管理（第二期）
管理奖学金/助学金/勤工助学/困难补助。每条含金额、批次/年度、发放状态（待发放/已发放）。KPI 展示总额与待发放数，柱状图按项目类型分布。

### 9.7 重点学生档案（第三期 · 隐私保护锁）
对心理/经济/学业/家庭/行为类重点学生建档案，分一/二/三级。首次进入需设 **4 位密码**；之后查看需解锁，可「上锁」「忘记密码（保留数据）」。一级·跟踪中者在首页置顶。

### 9.8 心理摸排台账（第三期）
按量表（PHQ-9/GAD-7/SCL-90/SAS/自编问卷）记录摸排，得分 + 等级（正常/轻度/中度/重度）。环形图展示等级分布、柱状图展示数量；**重度·未结案**在首页置顶并提示处理人。

### 9.9 毕业生档案与就业统计（第三期）
记录毕业年份、就业状态（已就业/升学/出国/公务员/入伍/创业/待就业/暂不就业）、单位/岗位/地点/薪酬/是否签约。KPI 展示就业率、升学出国、公务员录用。

### 9.10 政策智库库（第四期）
收集政策文件，按思想政治/学籍/资助/就业/心理/安全等分类，记录发布单位、发布日期、文号、关键词、摘要、链接，可「收藏」。顶部搜索框支持标题/单位/关键词全文检索。

### 9.11 工作素材收藏夹（第四期）
收藏讲话稿/班会PPT/活动方案/典型案例/图文素材/制度文件，记来源、标签、内容。便于班会、培训时快速取用。

### 9.12 科创竞赛平台（第四期）
管理数学建模/电子设计/互联网+/挑战杯/机器人大赛/智能车/创新创业 7 类竞赛，记主办单位、报名截止、参赛学生、获奖情况。**临近截止（14 天内）或逾期**的赛事会在首页提醒。

### 9.13 通知·流程·表单模板库（第四期）
沉淀通知/流程/表单三类模板，记适用场景与模板正文，一键复制复用，减少重复起草。

## 10. 工作留痕 / 小结

按月 / 自定义周期，自动汇总：

- 各职责下完成任务数；
- 重点学生谈话与回访情况；
- **专项模块统计**：走读 / 去向 / 评优数、请销假待审批数、考勤条数、工作节点逾期数、学业预警红 / 橙 / 黄数、帮扶跟踪数、奖助待发放数、重点学生一级数、心理重度数、就业落实数、政策收藏数、竞赛报名数、模板数；
- 待办与逾期概览。

点「生成小结」得到一段可直接复制进周报 / 月报的文字，含**下一步计划**（带截止日期）；也可直接点「本周小结」「本月小结」一键导出对应区间的结构化 TXT。页面含九项职责工作量柱状图和占比环形图。

## 11. 平台联动

进入「联动」页：

- **生成交换包**（v7）：导出当前全部数据集（students / tasks / talks / stay / leave / honor / pleave / attend / node / warn / help / grant / focus / psych / graduate / policy / material / comp / tpl / custom / stats）及附件清单为 JSON 文件；兼容导入 v1–v6。
- **导入交换包**：把平台导出的 JSON 导入本工作台（支持合并 / 覆盖两种模式）；
- **字段对照表**：查看本工作台字段与平台字段的映射；
- **扩展接口说明**：`CWB.bridge` 各方法用途；
- **危险操作区**：清空全部数据、清空示例数据（均需二次确认）。

## 12. 数据备份与恢复

首屏顶部常驻两个按钮：

- **导出 JSON 备份**：把全部数据导出成一个文件，存 U 盘 / 网盘；
- **导入恢复**：换电脑或误删后，用备份文件一键还原，**不限条数**。

另外：
- 所有列表类模块均支持 **CSV 导出**（带 BOM，Excel 打开不乱码）；
- 数据达到 30 条，首页会温和提示「建议导出备份」；
- 清空数据有二次确认弹窗，防误删。

## 13. 常见问题

**Q：数据会丢吗？**
只要不清理浏览器缓存、不换设备不备份，就不会丢。但浏览器缓存可能被清理工具误删，所以**定期导出备份**是好习惯。

**Q：换电脑怎么办？**
在旧电脑点「导出 JSON 备份」，新电脑打开工作台点「导入恢复」即可。

**Q：示例数据怎么清掉？**
「联动 → 危险操作区 → 清空示例数据」，只删示例、不碰你的真实数据。

**Q：手机和电脑数据同步吗？**
不同步（数据在各自本机）。需要同步就用「导出 / 导入交换包」在两端传递。

**Q：会联网吗？**
不会。单文件、零外链，完全离线。

**Q：心理危机预警是什么？**
参照本院《心理危机预警库名单》，对学生进行校级/院级分级管理，记录发现方式和解除状态。未解除的预警会在首页红色置顶显示，确保不会遗漏。

**Q：三个新模块的字段从哪来的？**
均参照本院真实工作台账文件校准：校外住宿→《校外住宿学生信息汇总表》、假期去向→《暑假学生去向统计表》、评优榜样→《青春榜样汇总》《五四评比先进个人汇总》。
