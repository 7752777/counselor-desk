# 使用指南

本指南面向一线辅导员，介绍如何把「辅导员工作台」用起来。无需任何技术背景。

---

## 1. 打开方式

- **电脑**：双击 `index.html`，用 Chrome / Edge / Safari 等任意浏览器打开。
- **手机**：用手机浏览器打开文件（微信里可直接打开 HTML），然后「分享 → 添加到主屏幕」，之后像 App 一样点击进入，离线也能用。
- **首次打开**：自动载入示例数据（5 名学生、6 条任务、4 次谈话），其中 1 条任务处于「逾期」状态，用于演示红色提醒。示例数据全部带 `示例` 标记，可一键清空。

---

## 2. 首页 · 今日要处理

打开后第一屏就是「今日要处理」，它自动聚合：

- 逾期的任务（**红色**标注）；
- 今天该做的任务；
- 3 天内到期的任务；
- 谈话回访已到期的记录；
- 重点关注学生按等级该谈的周期到了。

每条都有「一键处理」按钮，点一下即可标记完成或跳转到对应模块。

> 铁律：昨天没做完的事，不会凭空消失，会自动滚到今天的列表里。

首页还提供：
- **KPI 卡片**：任务总数 / 本周完成 / 重点关注人数 / 待回访数；
- **快速记录**：随手记一条任务或一次谈话；
- **九项职责工作量**：按 43 号令九大职责统计你近期投入，用横向柱状图展示。

---

## 3. 任务模块

三种状态：**待办 / 进行中 / 已完成**。每条任务可设置：

- **职责归属**：九大职责之一（决定首页工作量统计）；
- **优先级**：P0 紧急 / P1 常规 / P2 长期；
- **来源**：学校下发 / 学院安排 / 平台下发 / 自主计划 / 学生诉求；
- **截止日期**：`due`；
- **说明**：`desc`；
- **关联平台任务 ID**：`platform_ref`（与重型平台联动时用，可选）。

新增任务：点「+ 新建任务」填写表单即可。逾期任务在首页和列表里标红。

---

## 4. 学生模块

花名册 + 重点关注两层。

字段分两类：
- **与平台对齐的字段**（便于将来联动）：学号、姓名、性别、班级、专业、年级、学院、辅导员、在册状态；
- **本地扩展字段**：手机号、宿舍、重点关注类型、关注等级、备注。

**重点关注类型**：心理关注 / 学业预警 / 经济困难 / 身体状况 / 就业困难 / 行为纪律 / 家庭特殊。

**关注等级 → 回访周期**：

| 等级 | 名称 | 建议周期 | 说明 |
| --- | --- | --- | --- |
| L1 | 一级（重点） | 每 7 天 | 建议每周至少谈话 1 次 |
| L2 | 二级（关注） | 每 14 天 | 建议每两周谈话 1 次 |
| L3 | 三级（一般） | 每 30 天 | 建议每月谈话 1 次 |
| — | 不设关注 | — | 不纳入周期提醒 |

系统会根据「最后谈话日期 + 等级周期」自动算出该谈的时间，并在首页提醒。

---

## 5. 谈话模块

每次谈心谈话记一条：

- 日期、学生、所属职责、谈话方式（面谈 / 电话 / 线上 / 家访 / 集体）；
- **研判**：本次谈话的判断与结论；
- **是否需回访**：勾选后进入回访队列；
- **回访完成**：处理后在首页标记。

周期谈话提醒：重点关注学生到达等级周期时，首页自动列出「该谈了」。

---

## 6. 工作小结

按月 / 自定义周期，自动汇总：

- 各职责下完成任务数；
- 重点学生谈话与回访情况；
- 待办与逾期概览。

点「生成小结」得到一段可直接复制进周报 / 月报的文字，含**下一步计划**（带截止日期）。

---

## 7. 联动（与重型平台）

进入「联动」页：

- **生成交换包**：导出当前学生 / 任务 / 谈话为 JSON 文件，交给平台导入；
- **导入交换包**：把平台导出的 JSON 导入本工作台（支持合并 / 覆盖两种模式）；
- **字段对照表**：查看本工作台字段与平台字段的映射；
- **扩展接口说明**：`CWB.bridge` 各方法用途；
- **危险操作区**：清空全部数据、清空示例数据（均需二次确认）。

---

## 8. 数据备份与恢复

首屏顶部常驻两个按钮：

- **导出 JSON 备份**：把全部数据导出成一个文件，存 U 盘 / 网盘；
- **导入恢复**：换电脑或误删后，用备份文件一键还原，**不限条数**。

另外：
- 记账 / 列表类数据支持 **CSV 导出**（带 BOM，Excel 打开不乱码）；
- 数据达到 30 条，首页会温和提示「建议导出备份」；
- 清空数据有二次确认弹窗，防误删。

---

## 9. 常见问题

**Q：数据会丢吗？**
只要不清理浏览器缓存、不换设备不备份，就不会丢。但浏览器缓存可能被清理工具误删，所以**定期导出备份**是好习惯。

**Q：换电脑怎么办？**
在旧电脑点「导出 JSON 备份」，新电脑打开工作台点「导入恢复」即可。

**Q：示例数据怎么清掉？**
「联动 → 危险操作区 → 清空示例数据」，只删示例、不碰你的真实数据。

**Q：手机和电脑数据同步吗？**
不同步（数据在各自本机）。需要同步就用「导出 / 导入交换包」在两端传递。

**Q：会联网吗？**
不会。单文件、零外链，完全离线。
