# 数据格式与联动约定

本文档定义辅导员工作台的本地数据格式、与重型「办公网站」平台的字段对照、交换包结构（v5），以及二次开发接口约定。目的是让本工作台未来能与平台**无缝联动**，且改造时可被 AI 可靠地理解和扩展。

---

## 1. 存储位置与命名空间

- 所有数据存于浏览器 `localStorage`；
- key 统一前缀：`cwb_v1_`；
- 数据以 JSON 字符串存储（写入时 `JSON.stringify`，读取时 `JSON.parse`）；
- 示例：

| key | 内容 | 版本 |
| --- | --- | --- |
| `cwb_v1_students` | 学生数组 | v1.0 |
| `cwb_v1_tasks` | 任务数组 | v1.0 |
| `cwb_v1_talks` | 谈话记录数组 | v1.0 |
| `cwb_v1_stay` | 校外住宿/走读数组 | v2.1 |
| `cwb_v1_leave` | 假期去向数组 | v2.1 |
| `cwb_v1_honor` | 评优榜样数组 | v2.1 |
| `cwb_v1_pleave` | 请销假数组 | v3.0.0 🆕 |
| `cwb_v1_attend` | 考勤记录数组 | v3.0.0 🆕 |
| `cwb_v1_node` | 工作节点数组 | v3.0.0 🆕 |
| `cwb_v1_warn` | 学业预警数组 | v3.0.0 🆕 |
| `cwb_v1_help` | 学业帮扶数组 | v3.0.0 🆕 |
| `cwb_v1_grant` | 奖助勤补数组 | v3.0.0 🆕 |
| `cwb_v1_focus` | 重点学生档案数组 | v3.0.0 🆕 |
| `cwb_v1_psych` | 心理摸排数组 | v3.0.0 🆕 |
| `cwb_v1_graduate` | 毕业生档案/就业数组 | v3.0.0 🆕 |
| `cwb_v1_policy` | 政策智库数组 | v3.0.0 🆕 |
| `cwb_v1_material` | 工作素材数组 | v3.0.0 🆕 |
| `cwb_v1_comp` | 科创竞赛数组 | v3.0.0 🆕 |
| `cwb_v1_tpl` | 模板库数组 | v3.0.0 🆕 |
| `cwb_v1_settings` | 设置（如辅导员姓名、是否初始化） | v1.0 |
| `cwb_v1_custom` | 自定义模块数据 | v1.0 |

> 单域名上限约 5MB，日常纯文本够用。不存图片等大文件。

## 2. 实体结构

### 2.1 学生 `student`

字段分**平台对齐字段**（与重型平台同名）、**校准后本地字段**（参照本院真实表格）、**其他本地扩展字段**。

| 字段 | 说明 | 类别 | 来源 |
| --- | --- | --- | --- |
| `student_number` | 学号 | platform | — |
| `full_name` | 姓名 | platform | — |
| `gender` | 性别 | platform | — |
| `class_name` | 班级 | platform | — |
| `major_name` | 专业 | platform | — |
| `grade` | 年级 | platform | — |
| `college_name` | 学院 | platform | — |
| `counselor_name` | 辅导员 | platform | — |
| `enrollment_status` | **学生当前状态**（在读/休学/复学/退学/毕业/结业） | platform | 成绩表校准 |
| `politics` | **政治面貌**（中共党员/预备党员/入党积极分子/共青团员/群众/其他） | local | 青春榜样校准 |
| `phone` | 手机号 | local | — |
| `dorm` | 宿舍 | local | — |
| `focus` | 重点关注类型（见下） | local | — |
| `focus_level` | 关注等级 L1/L2/L3/空 | local | — |
| `crisis_level` | **危机预警级别**（校级/院级/空） | local | 心理危机预警库校准 |
| `crisis_way` | **危机发现方式**（自我报告/普查发现/其他人发现/其他） | local | 心理危机预警库校准 |
| `crisis_relieved` | **是否已解除预警**（布尔） | local | 心理危机预警库校准 |
| `note` | 备注 | local | — |

规范化函数：`CWB.norm.student(s)`。示例数据会被打 `_demo:true` 标记。

重点关注类型 `focus` 取值（来自 `CWB.consts.FOCUS` 常量）：
`psych` 心理关注 / `study` 学业预警 / `econ` 经济困难 / `health` 身体状况 / `career` 就业困难 / `disc` 行为纪律 / `family` 家庭特殊。

### 导入模式

`CWB.bridge.applyPackage(pkg, mode)`
- `'merge'`（推荐）：按 `id`（学生按 `student_number`）合并，已存在则覆盖字段，不存在则追加；

## 5. CSV 约定

- 导出的 CSV 带 **UTF-8 BOM**（`\uFEFF` 前缀），Excel 打开中文不乱码；
- 所有列表类视图均支持「导出 CSV」按钮；
- CSV 表头格式：`中文名(英文字段名)`，便于人工阅读和程序解析；
- 解析用 `CWB.utils.parseCSV`，兼容基础引号转义；
- 日期格式统一 `YYYY-MM-DD`；
- 学生导入支持中文表头自动映射（见 `CSV_MAP` 常量）。

## 6. API 直连预留（未来）

`CWB.bridge` 已声明以下方法，当前为占位，实现 `request` 后可启用：

- `request(path, init)` —— 统一的网络请求封装（需自行实现 fetch + 鉴权 + 跨域处理）；
- `pullTasks()` —— 从平台拉取任务写入本地；
- `pushSummary(scope)` —— 把本地工作小结推送到平台。

> 安全边界：本地数据默认不外传。任何直连都需在用户明确授权下进行，且不得把含真实学生信息的备份文件未经脱敏提交到公开仓库。
