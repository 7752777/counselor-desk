# v4.0 迁移与备份说明

## 从 v3.9 迁移

1. 在旧版本“平台联动”导出完整 JSON，或导出数据内置便携 HTML。
2. 打开 v4.0，选择“备份与迁移”中的恢复入口。
3. 选择合并或覆盖；迁移前 v4.0 会先生成本机回退快照。
4. 检查学生总数、照片索引、业务台账和敏感字段后再清理旧环境。

v4.0 交换包版本为 7，兼容 v1–v6。未知字段进入 `custom_fields`，不会静默丢弃。

`CWB.store` 仍保留用于 v3.9 兼容导入/恢复，并标记 `compatibilityOnly: true`；v4.0 新模块应使用异步 `CWB.repositories`、`CWB.attachments` 和 `CWB.backup`。

桌面端结构化记录落在加密 SQLite WAL 数据库，附件落在 Electron 保险库；网页端业务记录和附件索引落在 IndexedDB。`.cwbk` 清单包含附件元数据与内容哈希，口令使用 Argon2id + HKDF + AES-256-GCM；旧 PBKDF2 v7 包仍可恢复。

## 加密备份

桌面版将数据和附件写入本机保险库，备份文件使用 `.cwbk` 后缀。备份口令至少 8 位；忘记口令无法恢复。网页版可生成相同格式的手动加密备份，但浏览器不能保证页面关闭后按计划写入指定目录。

自动备份支持每日、每周和每月。应用未运行时不会常驻后台，下次启动会检查漏跑任务并补做一次。

大文件导入使用独立 Worker 解析 Excel/CSV；导入检查点和临时区均保存在本机，文件哈希或映射版本变化时会拒绝直接续传并要求重新开始。

## 手机与桌面端协同

当前公开版本不提供账号、云数据库或后台同步服务，因此手机不能直接“连上”桌面端的本地 SQLite。推荐使用工作包完成一次清晰的手动往返：

1. 桌面端进入“平台联动 → 备份迁移”，点击“导出手机工作包”，把 JSON 文件通过数据线、局域网文件传输或可信的文件工具放到手机。
2. 手机打开网页版，在“备份迁移”中导入工作包，完成查询、增删改后点击“导出手机工作包”。
3. 把手机生成的回传包带回桌面端，先导出当前备份，再选择“合并”或“覆盖”。合并按稳定 ID 和“学号 + 培养层次”识别记录，覆盖会替换当前工作区。

这个流程不是实时同步，也不会自动把数据上传到第三方；它更适合临时外出查看、现场补记和回到办公室后的集中回传。若未来需要多人同时编辑、自动推送或冲突解决，需要另立账号、权限、服务端加密和审计项目。

## 测试数据快照

在正式导入前可以把样例 A 保存为“原始状态”，清空当前工作区后测试样例 B；测试结束进入同一页面选择快照并恢复。快照包含学生、业务台账、分类资料和附件索引，恢复前仍建议保留一份独立加密备份。
