# 二次开发指南

本工作台的核心设计目标之一：**每位辅导员都能用 AI 在本地对工作台做进一步完善、维护、创意 DIY**，而不必成为前端工程师。

整个应用通过全局对象 **`window.CWB`** 暴露扩展点。你（或你让 AI 帮忙）只需在 `index.html` 末尾、或在自己新建的一个 `<script>` 里调用这些接口，就能加字段、加模块、接平台。

---

## 1. 全局对象结构

```js
window.CWB = {
  version,            // 当前版本号
  db,                 // 当前内存数据快照（students/tasks/talks/settings）
  store,              // 数据读写层（localStorage 封装）
  schema,             // 实体字段定义
  ui,                 // 弹窗 / 表单 / 提示组件
  hooks,              // 事件钩子
  bridge,             // 联动桥
  modules,            // 模块注册器
  consts: { DUTIES, FOCUS, LEVELS, PRIOS, SOURCES, TALK_WAYS },
  utils: { esc, uid, today, shiftDay, daysFromToday, cnDate, toCSV, parseCSV, download },
  save,               // 写盘 + 触发渲染
  render,             // 重新渲染当前视图
  go(view),           // 切换视图
  norm: { student, task, talk },  // 数据规范化函数
};
```

---

## 2. 数据层 `CWB.store`

```js
CWB.store.read(key);            // 读一个 key（已 JSON.parse）
CWB.store.write(key, value);    // 写一个 key（自动 JSON.stringify + 持久化）
CWB.store.remove(key);          // 删除
CWB.store.keys();               // 列出全部 key
CWB.store.bytes();              // 已用空间（字节），用于容量提示
```

数据 key 统一前缀 `cwb_v1_`。例如学生列表存在 `cwb_v1_students`。

---

## 3. 实体与字段 `CWB.schema`

`schema.student` / `schema.task` / `schema.talk` 是字段定义对象，每项形如：

```js
student_number: { label:'学号', platform:true,  local:false },
phone:          { label:'手机号', platform:false, local:true },
```

- `platform:true` 表示字段与重型平台同名，便于联动；
- `local:true` 表示本工作台本地扩展字段。

**加一个本地字段**（例：给学生加「民族」）：

```js
CWB.schema.student.nation = { label:'民族', platform:false, local:true };
// 之后录入 / 表格渲染会自动带上这一列
```

> 注意：加字段只改 `schema`，历史数据用 `CWB.norm.student()` 重新规范化即可兼容。

## 4. UI 组件 `CWB.ui`

```js
CWB.ui.modal({ title, html, onOpen(mask, close) });  // 通用弹窗
CWB.ui.confirm(text).then(ok => { ... });            // 二次确认
CWB.ui.toast(msg);                                   // 轻提示

// 表单生成器：自动渲染 + 收集
CWB.ui.form({
  title: '新建任务',
  fields: [
    { k:'title',  label:'标题', type:'text',   required:true },
    { k:'duty',   label:'职责', type:'select', options:CWB.consts.DUTIES },
    { k:'prio',   label:'优先级', type:'select', options:CWB.consts.PRIOS },
    { k:'due',    label:'截止', type:'date' },
    { k:'desc',   label:'说明', type:'textarea' },
  ],
  onSubmit(values) { /* values 为收集到的对象 */ },
});
```

`type` 支持：`text` / `textarea` / `select` / `date` / `number` / `checkbox` / `chips`。

---

## 5. 事件钩子 `CWB.hooks`

```js
CWB.hooks.on('store:write',  (key) => { ... });   // 任意写盘后
CWB.hooks.on('view:render',  (view) => { ... });  // 视图切换 / 重绘
CWB.hooks.on('module:register', (def) => { ... });// 新模块注册
CWB.hooks.emit('store:write', 'cwb_v1_tasks');   // 主动触发
```

用钩子可以在不改动核心逻辑的情况下，挂接「写盘后自动同步到某处」「渲染后注入自定义样式」等行为。

## 6. 注册自定义模块（最常用）

想加一个「宿舍检查」「请假审批」之类的新页签？用 `CWB.modules.register`：

```js
CWB.modules.register({
  key: 'dorm',                 // 唯一标识
  label: '宿舍检查',            // 导航显示名
  icon: 'i-daily',             // 复用内置 SVG 图标（见 index.html <symbol id="i-...">）
  render() {
    // 返回 HTML 字符串，或操作 DOM
    const list = CWB.store.read('cwb_v1_dorm') || [];
    return `<div class="card">
      <h3>宿舍检查记录</h3>
      <button onclick="CWB.modules._openDorm()">+ 新建</button>
      ${list.map(x => `<div>${CWB.utils.esc(x.room)} - ${CWB.utils.esc(x.note)}</div>`).join('')}
    </div>`;
  },
});
```

注册后，导航（PC 侧边栏 / 移动端底部 Tab）会**自动出现**「宿舍检查」入口，无需改导航代码。模块数据照常走 `CWB.store`，自动持久化、自动进备份。

## 7. 联动桥 `CWB.bridge`

```js
CWB.bridge.buildPackage(scope);   // 生成交换包 JSON（scope: 'all'|'students'|...）
CWB.bridge.applyPackage(pkg, mode);// 导入交换包（mode: 'merge'|'replace'）
CWB.bridge.stats(scope);          // 统计某范围数据量
CWB.bridge.request();             // API 直连占位（需自行实现）
CWB.bridge.pullTasks();           // 从平台拉取任务（占位）
CWB.bridge.pushSummary();         // 向平台推送小结（占位）
```

现阶段 `request/pullTasks/pushSummary` 是**预留通道**：实现 `request`（例如 `fetch` 到你的平台 API，注意跨域与鉴权）后，即可让平台主动与本工作台互通。交换包（JSON 文件）是当前已可用的联动方式。

---

## 8. 工具函数 `CWB.utils`

| 函数 | 用途 |
| --- | --- |
| `esc(s)` | HTML 转义（防 XSS，渲染任何用户输入前必用） |
| `uid()` | 生成唯一 ID |
| `today()` | 今天 `YYYY-MM-DD` |
| `shiftDay(str, n)` | 日期加减 n 天 |
| `daysFromToday(str)` | 距今天天数（负数 = 已逾期） |
| `cnDate(str)` | 格式化中文日期 |
| `toCSV(rows)` | 生成 CSV（带 BOM） |
| `parseCSV(text)` | 解析 CSV |
| `download(name, content, type)` | 触发浏览器下载 |

---

## 9. 扩展建议与约束

- **零外部依赖**是铁律：不要引入 CDN、框架、图表库。图表用内联 SVG 手写，图标用内置 `<symbol>`。
- **数据只存本地**：扩展模块的数据也走 `CWB.store`，自动进备份、自动隔离。
- **不要破坏隔离**：本仓库与「办公网站」重型平台互不依赖；扩展若需对接平台，走 `CWB.bridge`，不要直接 import 原项目代码。
- **命名空间**：新 key 沿用 `cwb_v1_` 前缀，避免冲突。
- **移动适配**：新增 UI 注意最小点击区 44×44px、输入框字号 ≥16px、窄屏单列。

## 10. 一个完整示例：加「宿舍检查」模块

把下面这段放进 `index.html` 末尾的启动逻辑之后（或单独 `<script>`）：

```js
CWB.modules.register({
  key: 'dorm',
  label: '宿舍检查',
  icon: 'i-daily',
  render() {
    const KEY = 'cwb_v1_dorm';
    const list = CWB.store.read(KEY) || [];
    CWB.modules._openDorm = () => CWB.ui.form({
      title: '宿舍检查',
      fields: [
        { k:'room', label:'宿舍号', type:'text', required:true },
        { k:'note', label:'情况', type:'textarea' },
        { k:'date', label:'日期', type:'date' },
      ],
      onSubmit(v) {
        const arr = CWB.store.read(KEY) || [];
        arr.unshift(Object.assign({ id: CWB.utils.uid() }, v));
        CWB.store.write(KEY, arr);
        CWB.render();
      },
    });
    return `<div class="card"><h3>宿舍检查</h3>
      <button onclick="CWB.modules._openDorm()">+ 新建</button>
      <ul>${list.map(x=>`<li>${CWB.utils.esc(x.room)} · ${CWB.utils.esc(x.note||'')}</li>`).join('')}</ul>
    </div>`;
  },
});
```

保存、刷新浏览器，导航里就多了一个「宿舍检查」。这就是老师用 AI 本地 DIY 工作台的范式。
