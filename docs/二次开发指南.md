# 二次开发指南

本工作台的核心设计目标之一：**每位辅导员都能用 AI 在本地对工作台做进一步完善、维护、创意 DIY**，而不必成为前端工程师。

整个应用通过全局对象 **`window.CWB`** 暴露扩展点。你（或你让 AI 帮忙）只需在 `index.html` 末尾、或在自己新建的一个 `<script>` 里调用这些接口，就能加字段、加模块、接平台。

---

## 1. 全局对象结构

```js
window.CWB = {
  version,            // 当前版本号（如 '2.2.0'）
  db,                 // 当前内存数据快照（全部数据集）
  store,              // 数据读写层（localStorage 封装）
  schema,             // 实体字段定义
  ui,                 // 弹窗 / 表单 / 提示组件
  hooks,              // 事件钩子
  bridge,             // 联动桥（交换包 v2）
  modules,            // 模块注册器
  consts: {
    DUTIES,           // 九项职责
    FOCUS,            // 重点关注类型
    LEVELS,           // 关注等级
    PRIOS,            // 优先级
    SOURCES,          // 任务来源
    TALK_WAYS,        // 谈话方式
    CRISIS_LEVELS,    // 危机预警级别（v2.1+）: ['校级','院级','']
    CRISIS_WAYS,      // 危机发现方式（v2.1+）: ['学生自我报告','心理普查发现','其他人发现','其他']
    STU_TYPES,        // 学生类型（v2.1+）: ['本科生','研究生']
    HONOR_TYPES,      // 评优申请类型（v2.1+）: [{v:'先锋',n:'低空先锋'}, ...]
    MORAL_LEVELS,     // 德育等级（v2.1+）: ['优','良','及格','']
    POLITICS,         // 政治面貌（v2.1+）: ['中共党员','中共预备党员',...]
  },
  utils: { esc, uid, today, shiftDay, daysFromToday, cnDate, toCSV, parseCSV, download },
  save,               // 写盘 + 触发渲染
  render,             // 重新渲染当前视图
  go(view),           // 切换视图
  norm: {
    student,          // 学生数据规范化
    task,              // 任务数据规范化
    talk,              // 谈话数据规范化
    stay,              // 走读数据规范化（v2.1+）
    leave,             // 去向数据规范化（v2.1+）
    honor,             // 评优数据规范化（v2.1+）
  },
};
```

> `db` 是内存中的实时数据对象，包含以下数组：
> - `db.students` — 学生台账
> - `db.tasks` — 工作任务
> - `db.talks` — 谈心谈话
> - `db.stay` — 校外住宿/走读（v2.1+）
> - `db.leave` — 假期去向（v2.1+）
> - `db.honor` — 评优榜样（v2.1+）
> - `db.settings` — 工作台设置
> - `db.custom` — 自定义模块数据

## 2. 数据层 `CWB.store`

```js
CWB.store.read(key);            // 读一个 key（已 JSON.parse）
CWB.store.write(key, value);    // 写一个 key（自动 JSON.stringify + 持久化）
CWB.store.remove(key);          // 删除
CWB.store.keys();               // 列出全部 key
CWB.store.bytes();              // 已用空间（字节），用于容量提示
```

数据 key 统一前缀 `cwb_v1_`。例如学生列表存在 `cwb_v1_students`。

内置数据集的 key 映射：

| 数据集 | localStorage key |
| --- | --- |
| 学生 | `cwb_v1_students` |
| 任务 | `cwb_v1_tasks` |
| 谈话 | `cwb_v1_talks` |
| 走读 | `cwb_v1_stay` |
| 去向 | `cwb_v1_leave` |
| 评优 | `cwb_v1_honor` |
| 设置 | `cwb_v1_settings` |
| 自定义 | `cwb_v1_custom` |

## 3. 实体与字段 `CWB.schema`

`schema.student` / `schema.task` / `schema.talk` 是字段定义对象，每项形如：

```js
student_number: { label:'学号', platform:true,  required:true },
phone:          { label:'手机号', platform:false, local:true },
crisis_level:   { label:'危机预警级别', local:true },   // v2.1+
politics:       { label:'政治面貌', local:true },         // v2.1+
```

- `platform:true` 表示字段与重型平台同名，便于联动；
- `local:true` 表示本工作台本地扩展字段；
- `required:true` 表示表单必填。

### v2.1 新增字段一览

| 实体 | 字段 | 说明 | 来源参照 |
| --- | --- | --- | --- |
| student | `enrollment_status` | 学生当前状态（在读/休学/复学/退学/毕业/结业） | 成绩表 |
| student | `politics` | 政治面貌 | 青春榜样/五四评比 |
| student | `crisis_level` | 危机预警级别（校级/院级） | 心理危机预警库 |
| student | `crisis_way` | 危机发现方式 | 心理危机预警库 |
| student | `crisis_relieved` | 是否已解除预警 | 心理危机预警库 |

**加一个本地字段**（例：给学生加「民族」）：

```js
CWB.schema.student.nation = { label:'民族', platform:false, local:true };
// 之后录入 / 表格渲染会自动带上这一列
```

> 注意：加字段只改 `schema`，历史数据用 `CWB.norm.student()` 重新规范化即可兼容。

## 4. UI 组件 `CWB.ui`

```js
CWB.ui.modal({ title, body, footer, size, onOpen(mask, close) });  // 通用弹窗
CWB.ui.confirm(title, msg, onYes, danger);                        // 二次确认
CWB.ui.toast(msg, type, ms);                                       // 轻提示（type: 'ok'|'err'|'warn'）

// 表单生成器：自动渲染 + 收集 + 校验
CWB.ui.form({
  title: '新建任务',
  size: 'narrow',     // 'narrow'(420px) | ''(620px) | 'wide'(860px)
  fields: [
    { k:'title',  label:'标题', type:'text',   required:true },
    { k:'duty',   label:'职责', type:'select', options:CWB.consts.DUTIES },
    { k:'prio',   label:'优先级', type:'select', options:CWB.consts.PRIOS },
    { k:'due',    label:'截止', type:'date' },
    { k:'desc',   label:'说明', type:'textarea' },
    { k:'tags',   label:'标签', type:'chips', options:[{v:'a',n:'A'},{v:'b',n:'B'}] },
    { k:'agree', label:'同意', type:'checkbox' },
  ],
  onSave(values) { /* values 为收集到的对象 */ return false; /* 阻止关闭 */ },
});
```

`type` 支持：`text` / `textarea` / `select` / `date` / `number` / `checkbox` / `chips`。

`size` 可选值：
- `'narrow'` — 窄弹窗（420px），适合简单表单
- 不传或 `''` — 标准宽度（620px）
- `'wide'` — 宽弹窗（860px），适合复杂内容

## 5. 事件钩子 `CWB.hooks`

```js
CWB.hooks.on('store:write',  (payload) => { ... });   // 任意写盘后
CWB.hooks.on('view:render',  (payload) => { ... });  // 视图切换 / 重绘
CWB.hooks.on('module:register', (def) => { ... });// 新模块注册
CWB.hooks.emit('store:write', { key:'students', val:[] });   // 主动触发
```

用钩子可以在不改动核心逻辑的情况下，挂接「写盘后自动同步到某处」「渲染后注入自定义样式」等行为。

## 6. 注册自定义模块（最常用）

想加一个「宿舍检查」「请假审批」之类的新页签？用 `CWB.modules.register`：

```js
CWB.modules.register({
  key: 'dorm',                 // 唯一标识（用作 data-view 和存储 key）
  name: '宿舍检查',            // 导航显示名
  icon: 'i-daily',             // 复用内置 SVG 图标（见 index.html <symbol id="i-...">）
  render() {
    // 返回 HTML 字符串
    const list = CWB.db.dorm || [];  // 或 CWB.store.read('cwb_v1_dorm') || []
    return `<div class="card">
      <div class="card-hd"><h2><svg class="ic"><use href="#i-home"/></svg>宿舍检查</h2>
        <span class="sp"></span>
        <button class="btn btn-primary btn-sm" onclick="CWB.modules._openDorm()">+ 新建</button></div>
      <div class="card-bd">
        ${list.length ? list.map(x =>
          `<div class="todo-row"><div class="todo-main">
            <div class="todo-t">${CWB.utils.esc(x.room)}</div>
            <div class="todo-m">${CWB.utils.esc(x.note||'')}</div></div></div>`
        ).join('') : '<div class="empty">暂无记录</div>'}
      </div>
    </div>`;
  },
});
```

注册后，导航（PC 侧边栏 / 移动端底部 Tab）会**自动出现**「宿舍检查」入口，无需改导航代码。模块数据照常走 `CWB.store` 或 `CWB.db`，自动持久化、自动进备份。

> **移动端适配提示**：自定义模块的 render 返回 HTML 会自动进入主内容区，移动端会自动单列堆叠。但请注意按钮最小点击区 ≥44px、输入框字号 ≥16px。

## 7. 联动桥 `CWB.bridge`

```js
CWB.bridge.PACKAGE_VERSION;     // 当前交换包版本号（= 2）
CWB.bridge.buildPackage(scope);   // 生成交换包 JSON
// scope 可选: { from:'2026-01-01', to:'2026-06-30', students:false }
// 不传 scope 则导出全部数据

CWB.bridge.applyPackage(pkg, mode);// 导入交换包（mode: 'merge'|'replace'）
CWB.bridge.stats(scope);          // 统计某范围数据量
CWB.bridge.baseUrl;               // 平台地址（只读）
CWB.bridge.enabled;               // 是否启用 API 直连（布尔）
CWB.bridge.request(path, init);   // API 直连占位
CWB.bridge.pullTasks();           // 从平台拉取任务（占位）
CWB.bridge.pushSummary(scope);    // 向平台推送小结（占位）
```

### 交换包 v2 结构（buildPackage 输出）

```json
{
  "package": "counselor-desk",
  "package_version": 2,
  "app_version": "2.2.0",
  "exported_at": "2026-08-04T00:00:00Z",
  "counselor": { "name": "", "college_name": "", "org_code": "" },
  "scope": {},
  "students": [...],
  "tasks": [...],
  "talks": [...],
  "stay": [...],       // v2.1+
  "leave": [...],      // v2.1+
  "honor": [...],      // v2.1+
  "custom": {},
  "stats": {
    "student_total": 0,
    "focus_total": 0,
    "crisis_total": 0,
    "task_total": 0,
    "task_done": 0,
    "talk_total": 0,
    "stay_total": 0,   // v2.1+
    "leave_total": 0,  // v2.1+
    "honor_total": 0,  // v2.1+
    "by_duty": [...]
  }
}
```

现阶段 `request/pullTasks/pushSummary` 是**预留通道**：实现 `request`（例如 `fetch` 到你的平台 API，注意跨域与鉴权）后，即可让平台主动与本工作台互通。交换包（JSON 文件）是当前已可用的联动方式。

## 8. 工具函数 `CWB.utils`

| 函数 | 用途 |
| --- | --- |
| `esc(s)` | HTML 转义（防 XSS，渲染任何用户输入前必用） |
| `uid()` | 生成唯一 ID（`x` + 时间戳 + 随机串） |
| `today()` | 今天 `YYYY-MM-DD` |
| `shiftDay(str, n)` | 日期加减 n 天 |
| `daysFromToday(str)` | 距今天天数（负数 = 已逾期，null = 未设日期） |
| `cnDate(str)` | 格式化中文日期（`2026-08-04` → `8月4日`） |
| `toCSV(rows)` | 生成 CSV（带 BOM `\ufeff`，Excel 直接打开不乱码） |
| `parseCSV(text)` | 解析 CSV 文本为二维数组 |
| `download(name, content, mime)` | 触发浏览器下载文件 |

## 9. 数据规范化函数 `CWB.norm`

所有写入 `DB` 的数据都应先经过 `norm*()` 函数规范化：

```js
CWB.norm.student(raw)   // → { id, student_number, full_name, gender, ..., _demo }
CWB.norm.task(raw)      // → { id, title, duty, status, ..., _demo }
CWB.norm.talk(raw)      // → { id, date, student_name, way, ..., _demo }
CWB.norm.stay(raw)      // → { id, student_name, grade_major, stu_type, ..., _demo }  // v2.1+
CWB.norm.leave(raw)     // → { id, name, class_major, home_addr, ..., _demo }         // v2.1+
CWB.norm.honor(raw)     // → { id, name, apply_type, politics, rank, ..., _demo }       // v2.1+
```

规范化函数的作用：
- 补全缺失字段（设默认值）
- 确保 `_demo` 标记正确传递
- 生成唯一 `id`
- 统一时间戳格式

## 10. 扩展建议与约束

- **零外部依赖**是铁律：不要引入 CDN、框架、图表库。图表用内联 SVG 手写，图标用内置 `<symbol>`。
- **数据只存本地**：扩展模块的数据也走 `CWB.store`，自动进备份、自动隔离。
- **不要破坏隔离**：本仓库与「办公网站」重型平台互不依赖；扩展若需对接平台，走 `CWB.bridge`。
- **命名空间**：新 key 沿用 `cwb_v1_` 前缀，避免冲突。
- **移动适配**：新增 UI 注意最小点击区 44×44px、输入框字号 ≥16px、窄屏单列。
- **XSS 防护**：任何用户输入渲染到 HTML 前，必须经过 `CWB.utils.esc()` 转义。

## 11. 一个完整示例：加「宿舍检查」模块

把下面这段放进浏览器控制台直接运行（或写入 `<script>` 标签）：

```js
// 1. 注册模块
CWB.modules.register({
  key: 'dorm',
  name: '宿舍检查',
  icon: 'i-home',
  render() {
    const list = CWB.db.custom._dorm || [];
    CWB.modules._openDormForm = function(data) {
      CWB.ui.form({
        title: data ? '编辑检查' : '新建检查',
        data: data || {},
        fields: [
          { k:'room', label:'宿舍号', type:'text', required:true, ph:'如 3号楼412' },
          { k:'note', label:'检查情况', type:'textarea', rows:3, ph:'卫生/安全/人员情况' },
          { k:'date', label:'检查日期', type:'date' },
          { k:'issue', label:'有无问题', type:'select', options:[{v:'',n:'无'},{v:'yes',n:'有'}] },
        ],
        onSave(v) {
          if (!CWB.db.custom._dorm) CWB.db.custom._dorm = [];
          if (data) {
            Object.assign(data, v);
          } else {
            CWB.db.custom._dorm.unshift(Object.assign({ id:CWB.utils.uid(), _date:new Date().toISOString() }, v));
          }
          CWB.save('custom');
          CWB.render();
          CWB.ui.toast(data ? '已更新' : '已添加', 'ok');
        }
      });
    };
    return `<div class="card">
      <div class="card-hd"><h2><svg class="ic" style="color:var(--brand)"><use href="#i-home"/></svg>宿舍检查</h2>
        <span class="sp"></span>
        <button class="btn btn-primary btn-sm" onclick="CWB.modules._openDormForm()">+ 新建</button></div>
      <div class="card-bd">
        ${list.length ? list.map((x,i) => `
          <div class="todo-row">
            <div class="todo-main">
              <div class="todo-t">${CWB.utils.esc(x.room)}${x.issue==='yes'?' <span class="tag tag-red">有问题</span>':''}</div>
              <div class="todo-m">${CWB.utils.esc(x.date||'')} · ${CWB.utils.esc(x.note||'')}</div>
            </div>
            <div class="todo-acts">
              <button class="btn btn-sm" onclick="CWB.modules._openDormForm(CWB.db.custom._dorm[${i}])">编辑</button>
            </div>
          </div>`).join('')
        : '<div class="empty"><svg class="ic"><use href="#i-inbox"/></svg><div>暂无检查记录</div></div>'}
      </div>
    </div>`;
  },
});

// 2. 切过去看看
CWB.go('dorm');
```

保存、刷新浏览器，导航里就多了一个「宿舍检查」。这就是老师用 AI 本地 DIY 工作台的范式。
