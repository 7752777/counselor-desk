# 辅导员工作台 v3.9.0 测试报告

测试日期：2026-08-05
结论：当前本地构建通过自动化、静态、发布完整性、依赖安全和 Chromium 真实浏览器验收，可作为 v3.9.0 候选发布包。

## 已执行验证

- 11 组自动化测试全部通过；覆盖 23 个页面、18 个模块导入导出与增删改闭环、学生安全导入、示例恢复、公开接口和 5,000 行压力测试。
- 18 个模块均完成“模板 → 预览/导入 → 刷新数据模型 → 再导出”回归；导入快照与撤销另有专门契约测试。
- CSV 覆盖 UTF-8、UTF-8 BOM、GB18030、错误表头、重复列、重复学号、同名/缺学号、前导零学号、公式文本、非法日期和超长内容。
- Excel 覆盖离线 XLS/XLSX、多工作表、合并标题行场景；真实浏览器中自动推荐“学生名单”工作表并识别第 3 行表头。
- 5,000 行学生预览测试通过，用时约 112 ms；未发生脚本崩溃或部分写入。
- 真实 Chromium 浏览器检查了 1366×768、390×844、320×568 布局，页面级横向溢出已受控；数据中心健康检查、浏览器能力与撤销入口可见。
- 浏览器控制台错误为 0。
- 内联 JavaScript 语法、公开接口、发布文件完整性检查全部通过。
- 生产依赖审计结果：无已知漏洞。离线表格解析器固定为 SheetJS 0.20.3。

## 发布边界

- 本报告不等同于 Windows Edge/Firefox ESR、macOS Safari 16+、WPS 和 LibreOffice 的全矩阵人工签收；这些环境仍需在公开发布前按使用手册中的验收清单各完成一次人工冒烟。
- v3.9 仅提供本机存储、备份和便携 HTML，不包含账号、服务器、手机同步或跨设备冲突处理。
- 真实敏感学生数据不得用于兼容性测试；发布包内样表均为脱敏虚构数据。
