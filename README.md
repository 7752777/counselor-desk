# 辅导员工作台（Counselor Desk）

一个**轻量、本地运行、零依赖**的辅导员日常工作台。单文件 HTML，双击即用，电脑、手机都能打开；数据只存在你自己的浏览器里，不外传、不联网。

> 定位：这是工作「台」，不是工作「平台」。为每位辅导员在本机独立使用而设计，替代重型系统里「太复杂、用不顺手」的日常场景。

---

## 一、它解决什么问题

很多高校已经有了功能完整的辅导员工作平台（多用户、多权限、安全合规）。但一线老师日常只需要：

- 今天有哪些事要处理？哪些逾期了？
- 哪个学生重点关注、该几时回访了？心理危机预警谁还没解除？
- 谈了一次话，留个记录、标记要不要跟进；
- 校外住宿/走读审批、假期去向统计、评优榜样申报；
- 月底写个工作小结，能直接生成文字。

这些事不值得登录重型系统、走完整流程。**辅导员工作台**把这些高频动作收敛到一个本地页面里，打开就用，关掉不丢。

---

## 二、与重型「办公网站」平台的关系（重要）

| 维度 | 重型平台（办公网站） | 本工作台 |
| --- | --- | --- |
| 部署 | 自有服务器，Next.js + PostgreSQL | 单文件 HTML，本地浏览器 |
| 用户 | 多用户、多角色、权限体系 | 单辅导员本机自用 |
| 数据 | 入库、集中管理 | `localStorage`，仅本机 |
| 定位 | 管理 / 统计 / 合规 | 个人日常提效 |

**隔离原则**：
- 本工作台在完全独立的目录 `counselor-desk/`，独立的 git 仓库；
- **不修改、不依赖**原「办公网站」项目任何文件；
- 字段命名刻意与原平台对齐（见《数据格式与联动约定》），为将来联动留口子；
- 联动现阶段用「文件交换包（JSON）」即可，API 直连通道已预留接口。

## 三、功能模块

### 核心视图（围绕教育部 43 号令九大职责）

依据《普通高等学校辅导员队伍建设规定》（教育部 43 号令）第五条，辅导员有九项工作职责。工作台以这九项为底色调色板与工作量统计维度：

| 代号 | 职责 | 简称 | 主色 |
| --- | --- | --- | --- |
| ideology | 思想理论教育和价值引领 | 思政引领 | 红 |
| party | 党团和班级建设 | 党团班级 | 玫红 |
| study | 学风建设 | 学风建设 | 蓝 |
| daily | 学生日常事务管理 | 日常事务 | 青 |
| psych | 心理健康教育与咨询 | 心理健康 | 绿 |
| net | 网络思想政治教育 | 网络思政 | 紫 |
| crisis | 校园危机事件应对 | 危机应对 | 橙 |
| career | 职业规划与就业创业指导 | 就业指导 | 琥珀 |
| research | 理论和实践研究 | 理论研究 | 灰 |

### 全量模块（v3.0.0 分四期交付；v3.1–v3.4 体验打磨）

**基础模块（首版 + v2.1）**
- 首页今日概览、工作任务、学生台账、谈心谈话、评优榜样（低空先锋/德育等六类）、校外住宿/走读、假期去向、工作留痕与小结、平台联动。

**第一期 · 事务与考勤**
- 请销假：登记 / 审批 / 销假，含起止、类型、事由、审批人；
- 考勤管理：缺勤记录按班级/月份统计，月度报表一键导出；
- 工作节点：周期工作（主题班会、谈心计划等）按截止日 + 提前提醒天数自动预警，支持日/周/月周期。

**第二期 · 学业与资助**
- 学业预警台账：挂科/旷课/学分不足等预警，红橙黄三级，未解除者在首页红色置顶，可一键解除或转建帮扶；
- 学业帮扶台账：学业/经济/心理/就业四类帮扶，跟踪中/已结束，可由预警一键转入；
- 奖助勤补管理：奖学金/助学金/勤工助学/困难补助，金额/批次/发放状态，KPI + 柱状图。

**第三期 · 重点关怀与就业**
- 重点学生档案（隐私保护锁）：心理/经济/学业/家庭/行为类 + 一/二/三级，4 位密码锁，一级跟踪中首页置顶；
- 心理摸排台账：PHQ-9/GAD-7/SCL-90/SAS/自编问卷等量表，正常/轻/中/重度，环形图 + 柱状图，重度未结案首页置顶；
- 毕业生档案与就业统计：毕业年份、就业状态（8 类）、单位/岗位/地点/薪酬，就业率/升学/公务员录用 KPI。

**第四期 · 资料与平台**
- 政策智库库：思想政治/学籍/资助/就业/心理/安全等分类 + 发布单位/文号/关键词/摘要/链接，收藏标记，全文检索；
- 工作素材收藏夹：讲话稿/班会PPT/活动方案/典型案例/图文/制度，来源/标签/内容，随手收藏；
- 科创竞赛平台：数学建模/电子设计/互联网+/挑战杯/机器人大赛/智能车/创新创业 7 类，主办单位/报名截止/参赛学生/获奖，临近截止首页提醒；
- 通知·流程·表单模板库：通知/流程/表单三类模板，适用场景 + 正文，复用即拷。

所有模块均：本地存储、CSV 导出、支持示例数据一键清空；字段命名与重型平台对齐，为联动留口子。

> 模块命名采用规范表述（台账/档案/平台/库），便于辅导员自行按需调整或二次开发 DIY。

**体验增强（v3.1–v3.4，模块集不变，交互与可视化升级）**

- **v3.1 视觉重做**：航空蓝玻璃拟态风格，深色顶栏 + 玻璃卡片，KPI / 装饰背景全面精致化；
- **v3.2 克制高级感**：回归纯色深蓝导航 + 纯白卡片 + 单一主色 + 极细边框（Linear / Vercel 风），去除花哨渐变与发光；
- **v3.3 易用与便携**：清理内部开发描述、新增「数据存储与备份」卡片、一键生成**自带数据的便携工作台**、首用示例数据提示、配套使用说明；
- **v3.4 信息获取与报表**：顶栏全局搜索（跨 8 类数据）、首页趋势折线图 + KPI 环比、侧栏分组折叠 / 常用钉住、按钮微交互、任务批量操作、占比环形图（学生关注结构 / 预警等级）、首页数据洞察卡、周报 / 月报一键导出。

## 四、快速开始

无需安装、无需构建、无需联网。

1. 把 `index.html` 拷到任意位置（U 盘、桌面、手机传自己都行）；
2. 双击用浏览器打开即可；
3. 首次打开会自动载入示例数据（覆盖学生、任务、谈话、走读、去向、评优，以及请销假/考勤/工作节点、学业预警/帮扶/奖助、重点档案/心理摸排/毕业生就业、政策智库/素材/竞赛/模板等全部模块），方便立刻看到效果；
4. 进入「联动 → 危险操作区」可清空示例数据，开始录入真实数据。

**手机上使用**：用手机浏览器打开后，点「分享 → 添加到主屏幕」，它就变成一个像 App 一样的图标，离线也能用。底部 Tab 栏支持单手操作。

## 五、数据说明（隐私）

- 所有数据存在浏览器 `localStorage`，命名空间 `cwb_v1_`；
- **不上传任何服务器**，断网可用；
- 首屏提供「导出 JSON 备份 / 导入恢复」，建议定期导出；
- 数据积累到 30 条会有温和备份提示；
- 导出可带走、可迁移、可换设备；
- 各模块均支持 CSV 导出（带 BOM，Excel 直接打开）。

## 七、与平台联动

现阶段：**文件交换包（JSON）**，版本 `PACKAGE_VERSION=5`（覆盖全部数据集）。

- 在工作台「联动」页点「生成交换包」，导出一个 JSON 文件；
- 把 JSON 交给重型平台导入，或反过来把平台导出的包在工作台「导入交换包」；
- 字段命名已对齐平台（学号、姓名、班级、学院等原名），导入导出零转换成本；
- 交换包包含：students / tasks / talks / stay / leave / honor / pleave / attend / node / warn / help / grant / focus / psych / graduate / policy / material / comp / tpl / custom / stats 全量数据。

未来：工作台已预留 `CWB.bridge.request()` / `pullTasks()` / `pushSummary()` 等 API 直连接口。详见《二次开发指南》与《数据格式与联动约定》。

## 八、二次开发（每位老师都能用 AI 本地改）

整个应用通过全局对象 **`window.CWB`** 暴露扩展点：

```javascript
// 在浏览器控制台试试
CWB.db.students        // 学生数组
CWB.db.stay           // 走读数组
CWB.db.leave          // 去向数组
CWB.db.honor          // 评优数组
CWB.db.pleave         // 请销假数组（v3.0+）
CWB.db.attend         // 考勤数组（v3.0+）
CWB.db.warn           // 学业预警数组（v3.0+）
CWB.db.policy          // 政策智库数组（v3.0+）
CWB.db.comp            // 科创竞赛数组（v3.0+）
CWB.consts.HONOR_TYPES // 评优类型常量
CWB.consts.POLITICS    // 政治面貌常量
CWB.consts.COMP_CATS   // 科创竞赛 7 类常量（v3.0+）
```

核心扩展点：

- `CWB.store` —— 数据读写层（localStorage 封装）
- `CWB.schema` —— 实体字段定义（可加本地字段）
- `CWB.ui` —— 弹窗 / 表单 / 提示组件
- `CWB.hooks` —— 事件钩子（`store:write` / `view:render` / `module:register`）
- `CWB.bridge` —— 联动桥（交换包 v5、API 预留）
- `CWB.modules.register(def)` —— **注册自定义模块**，自动插入导航
- `CWB.norm` —— 数据规范化函数（student / task / talk / stay / leave / honor / pleave / attend / node / warn / help / grant / focus / psych / graduate / policy / material / comp / tpl）

也就是说，老师可以用 AI 在本地给工作台加一个「请假审批」「宿舍检查」之类的新模块，不必动核心代码。详见《二次开发指南》。

## 十一、开源与贡献

本项目以 MIT 协议开源，欢迎 fork 后按本校实际场景改造。

- 仓库与「办公网站」重型平台**完全隔离**，互不干扰；
- 改造后若愿意回馈，欢迎提 PR；
- 因数据存本地，请勿把含真实学生信息的导出文件提交到公开仓库。
